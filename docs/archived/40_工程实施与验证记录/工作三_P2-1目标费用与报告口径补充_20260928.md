## 2. 当前正式目标

设固定基准节拍为`H0`，实际同步转站时刻为`P_q`，`H_q=P_q-P_(q-1)`；批次起始时固定工序总数为`N`。`normalize_by_n=True`时：

| 未加权指标 | 定义 | 归一化与结算 |
|---|---|---|
| `J_H` | `Σ_q max(H_q-H0,0)/H0` | 每次实际全线同步转站只计一次；绝对超期小时另报 |
| `D_T` | `(1/N) Σ_i |(S_i-P_(q_i-1)) - b_i^0|/H0` | 只在实际开工后确认该工序的周期内偏差；`normalize_by_n=False`时不除N |
| `D_W` | `(1/N) Σ_i (1-|W_i∩W_i^0|/m_i)` | 实际开工时确认最终团队偏差；`normalize_by_n=False`时不除N |
| `G` | `Σ_i g(n_i)`，`g(n)=λ1 n+λ2 max(n-1,0)` | 每次正式目标站位改变按增量结算；当前规则不除N |
| `R_T` | 相邻正式安排周期内时间位置变化之和 | 位置变化先除H0；`normalize_by_n=True`时再除固定N |
| `R_W` | 相邻正式安排团队替换比例变化之和 | `normalize_by_n=True`时除固定N |

现行加权目标：

```text
J_total = w_h*J_H + w_t*D_T + w_w*D_W + w_p*G + w_RT*R_T + w_RW*R_W
```

若`w_revision_time`、`w_revision_team`未显式配置，分别令`w_RT=w_t`、`w_RW=w_w`。`H0`在整批中固定；`N`采用批次基准工序数，不随开工数或预约数变化。`normalize_by_n=False`时JSON必须记录该配置，不能套用带`/N`的解释。

环境分别在正式发布修订、实际开工、实际同步转站时累计相应费用。站位变化次数已包含在`G`，相邻修订项只含`R_T/R_W`，不重复收改站费。基础实际奖励为`r_n=-(A_(n+1)-A_n)`；势函数塑形另计，不进入真实`J_total`。

## 3. 最终站位偏差只作报告

按真实开工时记录的`actual_start_station`与原始`base_station`比较。未开工工序不作为零偏差加入分母；后移次数也不等同于最终站位偏差。

报告同时保留已开工且站位已知的偏差数量、观测分母、固定批次总数和观测比例。只有整批完成、独立可行、所有任务均有真实开工站位时，`final_deviation_ratio`才给值；截断、失败或站位记录缺失时该终局比例为`null`，不以已开始子集冒充最终全批比例。另行报告累计后移次数、发生后移工序数和多次后移工序数。

## 4. 评测JSON

轨迹费用子结构版本为`work3_trajectory_cost_v2`：

- `metrics_unweighted`保存`J_H/D_T/D_W/G/R_T/R_W`，这些指标尚未乘目标系数，但各自仍按上表及配置归一化。
- `cost_components_weighted`保存五个可直接相加的已加权分项：`j_takt/d_time/d_team/j_postpone/j_revision`；`j_revision`内部另给时间、团队两项加权明细。
- `j_total`等于`cost_components_weighted`之和；同时保留`environment_cumulative_cost`及`ledger_reconciliation`，核对环境分项、独立评价器与`-Σr_actual`。
- 旧`raw_cost_components`和旧顶层费用名为兼容保留，但它们是已加权环境费用，不是未加权指标；新消费端应改读明确命名字段。
- `objective_normalization`记录`H0`、固定`N`和`normalize_by_n`；`metric_coverage`区分部分轨迹与已覆盖全部工序的轨迹。

## 5. 手算验收例

取`H0=10`，实际周期为14、11、10小时，则超期小时为`4+1+0=5`，`J_H=0.5`。令`N=2`：一项实际周期内偏移与基准相差1小时，`D_T=1/(10·2)=0.05`；四人团队换1人且另一工序未换人，`D_W=0.25/2=0.125`。取`λ1=0.1、λ2=0.2`，两项分别后移1次、2次，则`G=g(1)+g(2)=0.1+0.4=0.5`。若`R_T=0.1、R_W=0.125`且权重为`(w_h,w_t,w_w,w_p,w_RT,w_RW)=(2,3,4,5,7,8)`：

```text
J_total = 2*0.5 + 3*0.05 + 4*0.125 + 5*0.5 + 7*0.1 + 8*0.125
        = 1 + 0.15 + 0.5 + 2.5 + 0.7 + 1
        = 5.85
```

机器断言见`tests/work3/test_work3_p2_1_objective_report.py`。另有双机五站、每架5道工序的完整小批次，核对独立可行性、加权分项和、环境累计费用及未折扣/未塑形实际奖励和。
