## 二、工作一：基于异构图与自回归决策的多资源联合调度

### 2.1 针对的核心科学与工程问题
在工艺优先序 DAG、站位物理空间容量上限、工人技能资质等级（1~5级）多重强约束下，如何在已知全线任务与资源的静态条件下，克服传统分阶段割裂缺陷，端到端协调工序定序、站位划分与具体工人团队组建，生成高效且物理可行的基准生产计划？

### 2.2 已经完成的内容
1. **统一数学模型构建**：形式化建立了 APAL 周期作业模板优化模型，将工人工艺资质与团队效率折减显式纳入调度方程；
2. **异构图拓扑表征设计**：构建包含工序（Operation）、站位（Station）、工人（Worker）与技能（Skill）多类实体及关系的异构图，通过关系图注意力网络（GATv2）实现多维约束的全局状态联合编码；
3. **层级自回归解码与内生绑定**：设计“工序定序 $\to$ 站位指派 $\to$ 工人团队选拔”三层自回归指针网络，辅以前向动态掩码（Action Masking），将组合爆炸的团队选拔拆解为序列化决策；引入**内生工人站位绑定机制**（工人首次分配即锁定工位）；
4. **跨规模零样本泛化实验**：在合成算例上训练锁定单一套策略，直接零微调外推至 4 种真实工厂规模算例（283 至 3,182 物理工序），100% 满足物理约束。

### 2.3 独有的核心贡献
- **克服工位—工人分阶段割裂与预分配次优瓶颈**：已有文献大多采用预先固定工位工人数（Pre-assignment）或分步求解。工作一实现了**全局非绑定工人池与工位排程的内生协同**；
- **千级装配工序规模端到端直接外推能力**：突破了传统精确求解器在数百工序后内存溢出、元启发式算法耗时过长的限制，实现了 3000+ 工序的高效排程生成。

### 2.4 交付给工作二的接口与留存局限
- **交付内容**：
  1. **基准计划参照物 $\pi^0 = (m^0, W^0, B^0, C^0)$** 与基准周期跨度 $T_{\text{ref}}^0 = C_{\max}(\pi^0)$，为后续工作量化稳定性提供了不可或缺的坐标原点；
  2. **训练收敛的编码器与指针解码网络权重**，使得后续重调度模型无需从头冷启动。
- **留存局限（向工作二递进的必然性）**：
  - 工作一假定所有物料绝对准时到货，完全不具备应对在线突发扰动的动态适应能力；
  - 一旦发生物料延迟，原基准计划失效；若直接调用工作一模型重新全局求解，将引发全线任务大面积推倒重排，严重破坏现场既有安排。

## 三、工作二：基于图网络的预测—反应式调度与人员分配优化

### 3.1 针对的核心科学与工程问题
基准计划已发布并部分执行后，面对突发的供应链物料到货延迟，如何在**严格遵守现场冻结承诺（已开工工序不可中断、已选派工人站位锁定保持）**的前提下，对剩余未开工工序进行快速调整，实现恢复效率（完工跨度）与多维计划稳定性的兼顾？

### 3.2 已经完成的内容
1. **受约束预测—反应式重调度建模**：形式化定义带有冻结边界的重调度模型，划分冻结集合与可调集合，建立基准工人站位绑定关系的数学继承方程；
2. **多维计划稳定性量化体系**：突破以往仅考量时间偏差的局限，构建融合基准超期量、工序开工绝对偏差、站位变更率与团队变更率的复合评价函数；
3. **状态特征增广与参数迁移学习**：工序节点特征注入基准开工时间、基准站位、冻结标记与延误时长，底层权重直接复用工作一，在新扰动环境中微调收敛；
4. **全线真实扰动场景验证**：在 4 种规模、36 组锁定的物料延迟场景下完成全面评测，实现分钟级全线可行自愈。

### 3.3 独有的核心贡献
- **冻结承诺与资源绑定的自回归代数闭环**：不仅在目标函数中惩罚不稳定，更在算法底层通过动态动作掩码刚性锁死已开工工序与工人站位归属，杜绝执行层面的组织混乱；
- **人员分配与工序调度的联合反应式优化**：在继承既有工人站位绑定的前提下，仍对可调整工序优化具体合格人员团队组合，验证了人员柔性对稳定恢复的独立价值。

### 3.4 交付给工作三的接口与留存局限
- **交付内容**：
  1. 具备稳定性约束感知能力的重调度在线求解内核；
  2. 针对扰动状态特征增广与约束掩码处理的技术沉淀。
- **留存局限（向工作三递进的必然性）**：
  - **周期作业模板的假设边界**：工作二的重调度在“单周期模板”层面展开，本质上仍将全线飞机抽象为在各个站位复用同一套作业日程；
  - **无法处理真实多架次连续流动**：真实车间中各在制飞机的物料状态各不相同，单次模板修复无法解决“当前架次的妥协是否会导致后续架次在下一周期发生站位工序堆积与饥饿”。

## 四、工作三：基于状态表征学习的多架次飞机装配动态协同调度（拟开展）

### 4.1 针对的核心科学与工程问题
当装配线延伸至多架同型号飞机在五个站位连续流水流转、物料扰动在线动态到达时：
1. **多架次跨周期耦合问题**：在固定工人站位和同步脉动约束下，工序合法后移虽能缓解当前站位阻塞，却会增加该飞机下一周期的任务负荷并挤占下游工人，如何权衡当前等待与后续周期负荷？
2. **决策后果感知与状态表征学习问题**：如何让强化学习策略在面对高维组合状态时，有效感知调度动作对当前周期乃至后续周期转站时间的真实影响？

### 4.2 核心枢纽论证：“为什么多架次协同需要状态表征学习（时间残差预测与势函数塑形）？”

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│             核心枢纽：为什么多架次连续协同需要“时间残差预测＋势函数塑形”？              │
├────────────────────────────┬────────────────────────────┬──────────────────────────────┤
│ 1. 物理层：前向时空耦合    │ 2. 表征层：显式时间紧迫感知│ 3. 强化学习层：密集势函数塑形│
├────────────────────────────┼────────────────────────────┼──────────────────────────────┤
│ 多机连续流水推进，工序改派 │ 传统 GNN 仅学习综合特征，  │ 跨周期协同的真实节拍延迟反馈 │
│ 影响后续站位负荷与同步脉动 │ 缺乏显式时间刻度。时间残差 │ 极其稀疏延迟。通过修正时间构 │
│ 节点。当前局部妥协会击穿后 │ 预测头直接预见当前周期转站 │ 造保策略不变性的势函数差分， │
│ 续周期的节拍与人员缓冲。   │ 修正时间，直接输入动作头。 │ 为策略提供步步稠密的学习引导 │
└────────────────────────────┴────────────────────────────┴──────────────────────────────┘
```

1. **物理时空耦合的严峻性**：
   在单周期中，工序只能在当前站内消化或顺延；在多架次环境中，工序可合法改派至下一站位。后移虽能促成当前周期提早转站，但目标站位后续既有任务将被严重压缩。必须通过模型对时间后果的前摄预判来指导动作选择；
2. **图表征学习启发式时间修正量（算法创新主线）**：
   直接端到端预测长程时间极难收敛，但排程引擎已具备基线静态启发式估计 $\widehat P_q^h$。本研究让 Actor 图编码器表征 $z = f_\theta(s)$ 学习该启发式估计的**时间修正残差** $\delta_\psi(s)$，以实际转站结果进行监督学习，并将修正时间作为显式特征输入动作头；
3. **严格保策略不变性的势函数塑形（强化学习理论支撑）**：
   依据 Ng 等（1999）与 Devlin 等（2012）的势函数理论，利用修正后的周期跨度构建势函数 $\Phi(s)$，通过势差奖励 $\beta\{\gamma \Phi(s_{n+1}) - \Phi(s_n)\}$ 为智能体提供密集反馈，且在理论上保持最优策略的不变性；Critic 继续学习包含跨周期影响的综合回报。

### 4.3 核心技术内容
1. **单一事件驱动多架次执行环境**：
   - 统一协调五站多机连续流转，直至指定生产批次实际完成。取消独立虚拟规划层与两周期强制排程窗口；
   - 动作分支：当前站执行（选队+对齐，立即开工或预约）与合法后移（后移截断，待飞机到站后再统一由策略选队）；
2. **时间残差辅助表征与动作融合**：
   - Actor 增加时间预测头，学习启发式完工时间估计的归一化残差，真实转站时刻作为监督标签；修正时间显式输入动作决策头；
3. **势函数密集塑形与双层学习架构**：
   - 势函数提供即时时间引导，Critic 预测长期综合回报，形成短长结合的高效强化学习架构；
4. **方法库保留扩展**：
   - 互模拟度量（DBC）、原型网络（Kenny/ProtoX）等保留为方法库备选扩展，不作为当前主线。

### 4.4 严谨界定的“拟验证目标”
- **科学假设一**：基于时间残差预测的状态表征学习与动作显式输入，相较于纯综合回报图RL，能否显著改善多架次协同的节拍超期与稳定性指标？
- **科学假设二**：基于修正时间的势函数差分奖励塑形，能否有效加速多架次调度策略的收敛速度并提升训练稳定性？
- **科学假设三**：在 9 类解耦的正交扰动场景下，方法是否具备良好的跨时机与跨强度泛化性能？
