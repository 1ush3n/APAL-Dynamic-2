## 1. 总体定位与已确认条件

### 1.1 总体课题与研究主线
- **暂定总题目**：基于图表示与深度强化学习的飞机脉动装配线调度方法研究。
- **研究主线**：面向同型号飞机在同步脉动装配线上的重复生产，研究多资源耦合条件下的基准计划生成、物料扰动下的稳定性修复，以及面向扰动跨周期影响的多架次滚动协同决策。方法上由资源关系表示与联合决策，递进到基准及扰动条件化决策，再到受决策后果约束的任务相关表征学习。

### 1.2 基本背景与硬性约束
- **学生身份**：同济大学电子与信息工程学院控制科学与工程专业研二硕士生，2026年9月升研二。
- **结构与进度要求**：导师要求组织为三项研究工作。开题预计2026年10月中下旬，全部准备工作须在10月8日前完成；建议10月7日晚作为内部交付截止。
- **已有成果状态**：据用户确认，第一篇已录用CAC 2026；第二篇处于投稿准备/投稿阶段，拟投IEEE TSMC；两项研究均由用户独立完成。此处不将研究独立完成等同于单一论文署名。
- **模型与术语定义基准**：两项研究均随排程逐步确定工人站位绑定。完工跨度定义统一以第二篇为准：$H=C_{\max}$，为周期模板跨度；基准固定后 $T_{\text{ref}}^0=C_{\max}(\pi^0)$。第一篇旧有“五倍节拍”文字不作为开题统一定义。
- **数据与仿真前提**：已有工艺数据支持同型号多架次展开，但第三项仍需定义飞机进入、物料供应及信息揭示等仿真机制；这不等于已有真实连续运行日志。
- **第三项工作定性**：第三项允许完整修改数学模型、算法和仿真引擎。解释性是次要目标，性能改善是核心要求。

## 3. 第三项的核心研究假设与范围

- **核心研究假设**：对同型号飞机的连续脉动生产，若潜在状态表示保留了调度行为对即时损失、资源后续可用性和跨周期运行的影响，则可能改善滚动协同策略的决策质量与跨情境适应能力。该假设必须通过同一多架次环境中的受控比较检验。
- **情境与表征的准确定义**：情境不要求预先人工分类、命名或赋予人类语义。首先学习连续任务相关表示，再验证是否需要离散聚合、原型或软分组。奖励和转移产生训练信号，因此更准确的表述是“无需人工情境标签的表征学习”，而非完全没有监督信号。
- **拟优先验证方案**：基础滚动图强化学习；增加决策后果约束但不聚类；增加聚类/原型（若采用）；普通特征聚类对照。使用相同环境、信息可见性和相近训练/计算预算，以区分环境扩展、网络容量、后果表征和聚合机制的收益。

### 边界与默认设定（均可在技术路线阶段调整）：
1. **产品与资源假定**：同型号、共享工艺模板，但每架飞机有独立的任务完成状态、物料条件和实际站位；工人是产线共享的物理资源，不能随飞机复制。
2. **约束刚性**：同步脉动、飞机单站占用、前序、容量、技能与工人互斥为硬约束。已开工工序保持非抢占。任务变更惩罚主要针对尚未执行的计划分配。
3. **工序与站位移动**：工序改站仅在该架飞机实际到达可执行站位、满足前序和资源约束时允许；飞机不能为补做工序逆向返回或同时跨站执行。暂保留既有工人站位绑定，跨周期重新配置不作为首版必备任务。
4. **扰动信息假定**：先研究有持续时间和恢复时刻的物料短缺。未来真实到料结果仅在设定的揭示时刻进入策略；仿真器已生成的未来随机量不自动对策略可见。初版可在扰动揭示时给出恢复时间，后续再研究预测误差。
5. **多扰动扩展**：其他扰动作为扩展测试。工人缺勤影响共享资源供给，工时变化影响占用区间，执行中故障可能涉及中断；不能仅因均造成延迟就视为同一种释放时间变化。
6. **恢复目标定位**：物料恢复不保证累计延迟归零。分别评估继续传播是否受抑制、剩余延迟大小，以及有可压缩周期/资源余量时能否追赶基准；不保证所有情境都能恢复原始绝对时刻。
7. **稳定性基准锚定**：滚动优化可以更新内部计划，但稳定性评价保留原始基准，避免不断更换参照使偏离看似消失；同时可另报相邻两次已发布计划之间的变更。
8. **多目标权重管理**：首版固定一组主要权重并报告各原始指标，辅以权重敏感性分析。若未来要求单一模型适应多组权重，应显式条件化偏好或保留分量代价信息，避免加权和抵消造成不合理聚合。

## 4. 方法借鉴与尚待核验的增量

- **DBC 理论借鉴**：Zhang等的DBC研究使用奖励差异与后继分布差异学习面向控制的表示，并区分严格动作条件下的双模拟定义与用于学习的策略相关近似。它提供方法启发，不自动赋予本课题最优性或策略保持保证。[论文全文](https://arxiv.org/html/2006.10742v2)
- **待攻关专门难点**：变规模图中动作如何对应、可行行动集合差异如何保留、物理恢复时长如何进入后果描述、不同目标权重下何种信息不能被合并。当前策略下收益相似，不等于其他候选动作的优劣排序也相同。不能把工序编号一致当作动作语义一致。
- **新颖性状态定性**：三项已有成果的内容归属已建立；第三项方法增量暂定，须在下一步对照最接近的图强化学习、任务相关表征、行为相似性和滚动恢复文献核验。与组员研究的区别应落在研究问题、方法和评价贡献，而不是“首次考虑多架飞机”。
