## 一、总体研究定位

### 1.1 确认的总题目与三项工作名称

**确认总题目：基于图表示学习与强化学习的飞机脉动装配线调度方法研究**

| 层级 | 中文名称 | 英文名称 |
|---|---|---|
| **总体课题** | 基于图表示学习与强化学习的飞机脉动装配线调度方法研究 | Scheduling Methods for Aircraft Pulsating Assembly Lines Based on Graph Representation Learning and Reinforcement Learning |
| **工作一** | 基于异构图与自回归决策的多资源联合调度 | Joint Multi-Resource Scheduling via Heterogeneous Graphs and Autoregressive Decision-Making |
| **工作二** | 基于图网络的预测—反应式调度与人员分配优化 | Predictive–Reactive Scheduling and Workforce Allocation Optimization Using Graph Neural Networks |
| **工作三** | 基于状态表征学习的多架次飞机装配动态协同调度 | Dynamic Coordinated Scheduling of Multi-Aircraft Assembly via State Representation Learning |

*术语统一说明*：工作二正式标题采用“人员分配优化”；工作三“协同”指不同架次装配计划之间的协调（coordinated scheduling），multi-aircraft assembly 指多架飞机的装配实例，不译为 multiple sorties。

### 1.2 研究背景与意义

飞机脉动装配线（Aircraft Pulsating Assembly Line, APAL）通过全线同步脉动转站组织生产，各站位内的作业完成情况共同约束全线的生产推进节律。工艺优先序、多技能人员协作、站位物理容量及工人站位内生绑定等因素相互耦合，使得作业安排与资源配置成为直接决定装配周期与线体平衡的核心瓶颈。

1. **在无扰动基准阶段**：需要根据已知工序与有限人员生成高可行性、低跨度的基准生产计划；
2. **在突发物料扰动阶段**：需要在继承既有冻结承诺与人员站位绑定的物理刚性约束下，快速恢复可行性并严格抑制生产计划的多维偏离（开工时间、执行站位、团队变更）；
3. **在多架次连续生产阶段**：由于扰动跨周期、跨工位的动态传播，局部站位的调整会显著影响后续架次负荷与后续转站时刻，必须协调多架在制飞机的跨周期运行，权衡即时等待与远期负荷。

因此，本研究围绕**“基准计划构建—扰动响应恢复—连续生产协同”**三阶递进展开。在方法上，由多资源关系表示与联合决策，递进到基准及扰动条件化决策，再递进到受决策后果约束的任务相关状态表征学习。

### 1.3 总体研究目标与三大关键科学问题

围绕飞机脉动装配线的作业与资源耦合约束，研究从无扰动基准调度到扰动下稳定恢复、再到多架次连续生产协同的强化学习调度方法，形成兼顾生产效率、计划稳定性与跨周期运行表现的研究体系。

三个核心研究问题分别为：

1. **基准计划如何形成？** 在任务和资源拓扑已知时，如何在多实体复杂约束下自回归协调工序定序、站位指派与团队选拔，实现高效求解？
2. **既有计划如何恢复？** 在突发物料可用性扰动改变执行条件后，如何在继承冻结任务和人员绑定的刚性约束下，协调恢复效率与多维计划稳定性？
3. **连续运行如何协同？** 在多架飞机共同在制、生产信息动态更新时，如何通过任务相关的状态表征学习预见决策的跨周期时间后果，协同多架次工序重分配与同步转站？

## 三、工作一：基于异构图与自回归决策的多资源联合调度

### 3.1 研究定位
面向无外部扰动条件下的飞机脉动装配线，研究工序、站位和工人团队之间的联合决策问题，为后续扰动响应与动态运行提供基准计划参照和底层模型骨架。

### 3.2 拟解决的核心问题
在工序工艺优先序（DAG）、狭窄站位作业空间上限、工人技能等级资质等多重硬约束下，如何避免传统工位划分与人员配置的分步割裂，端到端联合确定工序、站位和合格工人团队，生成高效可行的基准计划？

### 3.3 核心内容与机制
1. **统一优化建模**：形式化建立 APAL 周期作业模板优化模型，显式刻画团队效率折减函数；
2. **多实体异构图表征**：构建包含工序、站位、工人与技能的多实体异构图，通过关系注意力机制实现全局拓扑联合编码；
3. **三层自回归指针决策**：依次自回归输出“工序 $\to$ 站位 $\to$ 工人团队”，结合动态掩码确保 100% 物理可行；
4. **内生工人站位绑定机制**：工人首次被选派即锁定其工位归属，实时追踪站位人力池消耗。

### 3.4 与后续工作的衔接
工作一生成无扰动基准模板 $\pi^0$ 并确定基准周期跨度 $T_{\text{ref}}^0 = C_{\max}(\pi^0)$，为工作二和工作三提供了稳定性衡量的基准坐标原点与网络初始化权重。

## 四、工作二：基于图网络的预测—反应式调度与人员分配优化

### 4.1 研究定位
面向突发物料延迟引起的基准计划失配，研究预测—反应式调度与人员分配优化。在继承冻结任务和既有工人站位绑定的前提下，联合调整可变工序的作业安排与具体团队，在恢复效率与计划稳定性之间取得平衡。

### 4.2 核心研究问题
在物料到货延迟发生、部分既有承诺不可更改的情况下，如何将基准计划与扰动信息融入图状态，在严格保护冻结区作业与人员绑定的物理可行域内，协调剩余任务的重排与团队重组？

### 4.3 核心内容与机制
1. **受约束预测—反应式重调度建模**：严格划分冻结集合与可调整集合，形式化继承工人的站位归属约束；
2. **基准与扰动状态增广**：将基准开工时间、基准站位、冻结标记及物料更新释放时间注入图节点；
3. **多维计划稳定性度量体系**：突破传统仅考核完工时间的局限，联合优化相对基准超期量、绝对开工时间偏差、站位变更率与团队变更率；
4. **多规模扰动情境验证**：在固定离线物料延迟测试情境下，验证秒级自愈求解与稳定性表现。

### 4.4 研究边界说明
工作二的动态性来自“基准计划形成后的信息更新与单次计划修复”，处理载体仍为周期作业模板层面。多架在制飞机在真实时间轴上的物理推进与跨周期级联传播，作为工作三的独立研究接口。

## 五、工作三：基于状态表征学习的多架次飞机装配动态协同调度

### 5.1 研究定位
面向多架同型号飞机在全线五个站位上的连续装配过程，显式跟踪在制飞机的实际物理位置、作业进度与物料可用性条件。通过学习任务相关的状态表征，预见当前调整对后续站位和未来周期的跨周期影响，支持随生产推进的多架次动态协同决策。

### 5.2 核心研究问题
**在固定工人站位和全线同步脉动约束下，当某架飞机的工序因物料延迟受阻时，如何通过受约束的工序相邻站位重分配与站内团队优化，权衡当前周期等待、后续周期任务负荷及连续生产稳定性？任务相关状态表征学习能否改善这种跨周期决策？**

### 5.3 运行机制与物理边界
1. **单一事件驱动执行环境**：统一协调五个站位上的多架飞机，连续推进至指定生产批次实际完成。取消独立虚拟规划层与强制两周期详细排程窗口；
2. **条件自回归动作结构**：
   - **留在当前站分支**：工序 $\to$ 当前站位 $\to$ 站内团队 $\to$ 二元对齐；立即开工或登记未来有效预约；
   - **合法后移分支**：工序 $\to$ 紧邻下一站位，动作立即截断；当场不选队、不占用工人，记录正式改派；待飞机实际转站到达目标站后，再与该站原有任务统一由策略选队；
3. **整线同步脉动放行条件**：当前周期归属各站的全部任务完成且工艺放行条件满足后，全线同步转站。严禁到点强行带走未完任务；
4. **改派代价引导**：对首次站位变更施加惩罚，对重复变更施加更重惩罚 $g(n) = \lambda_1 n + \lambda_2 [n-1]_+$，鼓励策略不后移或至多后移一次。

### 5.4 核心表征方法：启发式时间残差预测与势函数塑形
1. **残差辅助预测**：利用 Actor 图编码器表征 $z = f_\theta(s)$，增加时间修正头 $\delta_\psi(s)$，预测当前周期启发式完工时间估计的修正量：
   $$\widehat P_q = \max\{t, \widehat P_q^h(s) + H_0 \delta_\psi(s)\}$$
   在当前周期实际转站后，以真实转站时刻构造监督标签 $y = (P_q - \widehat P_q^h(s))/H_0$ 进行回归训练；
2. **动作头显式辅助输入**：将修正后的剩余时间 $\widehat R = \widehat P_q - t$ 等显式时间特征拼接输入动作决策头，使策略直接感知时间紧迫度；
3. **势函数密集奖励塑形**：基于修正后的周期跨度构建势函数 $\Phi(s) = -a \widehat H_q/H_0 - b [\widehat H_q - H_0]_+/H_0$，生成保策略不变性的势差奖励 $\beta\{\gamma \Phi(s_{n+1}) - \Phi(s_n)\}$；
4. **综合价值评估**：Critic 网络继续学习包含跨周期长期影响的真实综合回报；
5. **方法库保留扩展**：DBC 互模拟度量、ProtoX 原型网络等保留为方法库备选扩展，不作为当前主线。

### 5.5 优化目标与计账规则
- **效率主项**：各周期实际节拍超出基准节拍的部分 $J_{\text{takt}} = \sum_q [H_q - H_0]_+ / H_0$；
- **周期内开工位置偏差**：$D_{\text{time}} = \sum_i |b_i - b_i^0| / H_0$，其中 $b_i = S_i - P_{q_i-1}$，允许周期因扰动整体平移，不重复计罚绝对日历滞后；
- **人员稳定性**：实际开工时确认团队替换比例 $d(W, W^0) = 1 - |W \cap W^0|/m$；
- **计划修订代价**：正式修订时记录相邻安排变化及累计改站次数增量。

## 八、实验验证方案概览（工作三）

1. **扰动场景矩阵**：基于“工序开工可用性延迟”模型，构建 $3 \text{ 时机 (早/中/晚)} \times 3 \text{ 强度 (低/中/高)} = 9 \text{ 类}$ 解耦测试场景，全算法共用确定性扰动事件；
2. **四组主对比**：
   - 组 A：基准计划修复参照（启发式顺延与最小改动）；
   - 组 B：固定站位图强化学习（仅站内选队与对齐）；
   - 组 C：允许合法后移的图强化学习（启发式时间估计）；
   - 组 D：完整方法（残差预测＋动作辅助输入＋预测势函数）；
3. **五组内部消融**：系统检验时间辅助表征训练（E）、预测输入动作头（F）、预测势函数塑形（G）的独立增益与组合效用。
