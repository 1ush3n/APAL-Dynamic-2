## 一、 阶段结论与确认标题

本阶段没有必须继续向用户追问、才能形成开题模型的问题。已明确工作三的实际跨周期联系：未开工工序经合法改派后，改变后续站位的任务负荷；后续周期的整线同步转站可能因此受到影响。固定工人站位仍可保留。

### 1.1 总体课题与三项工作确认名称

| 层级 | 已确认名称 |
| :--- | :--- |
| **总体课题** | **基于图表示学习与强化学习的飞机脉动装配线调度方法研究** |
| **工作一** | 基于异构图与自回归决策的多资源联合调度 |
| **工作二** | 基于图网络的预测—反应式调度与人员分配优化 |
| **工作三** | 基于状态表征学习的多架次飞机装配动态协同调度 |

### 1.2 三项工作的衔接定位
*   **工作一**：生成无扰动条件下的基准模板，联合安排工序、站位与工人团队。
*   **工作二**：沿用基准计划，研究物料扰动下的预测—反应式调度与人员分配，继承已有冻结和绑定约束。
*   **工作三**：以多架实际飞机连续执行为对象，显式维护每架飞机的状态，统筹工序站位重分配、后续任务负荷和连续计划修订。

### 1.3 工作三的研究问题表述
> **核心研究问题**：  
> 在固定工人站位和同步脉动约束下，如何通过受约束的工序站位重分配与站内团队优化，权衡当前周期等待、后续周期任务负荷及全生产过程的计划稳定性？任务相关状态表征能否改善这种跨周期决策？

*注：这里的“协同”指不同架次装配计划之间的协调，不要求采用多智能体。*

## 二、 最终运行规则

| 事项 | 本阶段确认的设定 |
| :--- | :--- |
| **基准计划** | 首先生成无扰动基准模板，再按原定投产节奏展开为各架飞机的基准计划 |
| **基准是否重置** | **不重置**；实际延期或提前不能改变原始评价基准 |
| **工人站位** | 继承初始安排，在工作三研究视界内**固定**；暂不考虑跨站调人 |
| **团队调整** | 对允许调整的未开工任务，可在执行站位的固定工人中重新选队 |
| **调整耗时** | 初版不单独建模团队调整耗时，以变更惩罚表达调整代价；工序本身的团队相关作业时长仍正常计算 |
| **可改派工序** | 未完成、未开工、未冻结，且满足全部工艺与执行条件的工序 |
| **单次后移范围** | 对当前站位待处理任务，保留当前站位或改派至**紧邻下一站位** |
| **多次后移** | 必要时允许再次后移；不设置“全程最多一次”的统一硬上限 |
| **少移动的偏好** | 第一次正式站位变更就施加惩罚，第二次及以后增加额外惩罚，鼓励不移动或最多移动一次 |
| **最远执行位置** | 由合法站位、前后序关系、转站必完节点、设备及人员能力限定，不能无限后移 |
| **转站方式** | 所有站位完成修订后分配在本站的全部任务，并满足不可更改的转站条件后，**整线同步转站** |
| **时间目标** | 实际任务执行可早于或晚于原定计划，但提前与推迟均受惩罚 |
| **飞机物理位置** | 每架飞机同时只在一个站位；不能在未到达的站位提前执行工序 |
| **作业连续性** | 已开工工序不跨站中断后续做，转站前完成；已完成任务不重新安排 |
| **未来信息** | 决策只使用当时已知信息；不得读取仿真器未揭示的真实未来扰动 |

*“尽量最多移动一次”是优化偏好，不是硬约束，也不是保证训练结果必然满足的性质。*

## 三、 明确区分三份计划与实际状态

### 3.1 原始基准计划
记原始基准为 $P^0$。每架飞机的每道工序有固定的基准开工时刻、基准站位和基准团队。  
同一模板可以按不同飞机的原定投产时刻展开，但**后续评价不能随着实际脉动重新对齐时间原点**。否则，整线已产生的延期会被掩盖。

### 3.2 当前已发布计划
记第 $r$ 次正式修订的计划为 $P^r$。它决定此后允许执行的安排，也是下次修订时衡量“又改了多少”的参照。  
飞机A的任务改派不自动修改其他飞机的模板。其他飞机是否修订，须根据各自执行状态和整体目标决定。

### 3.3 实际执行状态
持续记录飞机位置、已完成工序、在制工序、未开工工序、实际资源占用、已知到料信息以及历史正式修订记录。  
网络内部试算方案不直接改变执行状态，不计入现场计划修改次数。

## 四、 工序后移与同步转站的准确含义

### 4.1 必须先改派，再按新任务集合执行
*   例如，飞机A在站位2的任务集合为 $\{a,b,c\}$。工序 $c$ 尚未开工且缺料，允许在站位3执行。
*   若保留原计划，站位2必须完成 $\{a,b,c\}$，才能与其他站位一起转站。
*   若正式将 $c$ 改派到站位3，站位2当前任务变为 $\{a,b\}$，站位3未来任务中增加 $c$。只有本站 $\{a,b\}$ 及其他站位当前任务全部完成、且各项转站条件满足后，才同步转站。
*   工序 $c$ 没有被删除或视为完成，它仍需在飞机实际到达目标站位后执行。**不得到原定转站时刻就自动跳过或后移未完成任务。**

### 4.2 不可通过改派绕过真实转站条件
*   若某工序必须在转站前完成，或者其后继任务被固定在本站，就不能仅通过改变该工序的站位标签使整线获得转站资格。
*   改派必须保留完整、可执行的后续计划。若无法构造可行改派方案，则沿用可行安排并等待物料或资源，接受延期；若已知条件导致任务本身无法完成，应报告不可行，不能以惩罚替代合法性。

### 4.3 当前站位与下一站位的动作掩码
对于飞机 $k$ 当前位于站位 $s_k$ 时，属于当前局部修复范围的工序 $i$：
$$\mathcal S_{ki}^{\mathrm{candidate}} = \{s_k, s_k+1\} \cap \mathcal S_{ki}^{\mathrm{feasible}}$$
*   **可行集合检查**：工艺站位资格、冻结状态、前后序关系、转站必完要求、目标站位设备与空间、固定工人的技能及团队可组建性。
*   该局部掩码不用于强行把全部未来工序压到当前和下一站位。原本就在更后站位的未来任务继续保留其未来安排。末站不存在下一站位，所有离线前必须完成的任务均须完成。
*   未来站位的可行性应按其预计执行区间检查，不能仅因该站位工人当前正在服务另一架飞机，就永久排除未来安排。

### 4.4 多次后移
*   可以在后续实际周期中再次修订，但每次都重新检查全部约束。例如由站位2改至3，飞机实际到达3后，必要且合法时再改至4。
*   同一物理周期内反复调用修复器，不应绕过“当前站位和下一站位”的限制，把工序连续推到多个更远站位。
*   合法站位集合可能不连续。若下一站位不合法，本方案不允许直接跨过它跳到更远站位；这是本研究的相邻调整限制。

### 4.5 转站时间
*   原定转站时间作为固定参考。实际转站依据各站位任务的实际完成状态和转站条件决定，允许提前或延期。
*   若暂不单独计算转站耗时，且无额外转站时间窗，在一个任务分配已确定、转站条件均满足的周期内，下一次转站由最后一个站位完成当前任务的时刻触发。实现时还应处理当前时刻、空站及空任务集合，不能使时间倒退。
*   若后续实际数据要求运输耗时或固定转站时间窗，应明确加入约束；本阶段不额外引入这些机制。

## 五、 站位变更奖励：第一次就惩罚，重复变更更重

### 5.1 次数的定义
令 $n_{ki}$ 表示同一架飞机、同一道工序在正式发布计划中的累计执行站位变更次数。保持站位不变不增加次数；改队不算站位变更，另计团队变化。  
若在飞机尚未转站前依法撤回一次改派，且该撤回被正式发布，也应计为一次站位变更，避免反复修改被漏计。此处统计的是计划改派，不是人员或已完成工序的物理搬运。

### 5.2 建议实现形式
采用下列分段代价作为后续实现的起点，具体数值尚未确认：
$$g(n) = \lambda_1 n + \lambda_2 [n-1]_+, \qquad \lambda_1 > 0, \; \lambda_2 > 0$$

| 累计变更次数 $n$ | 累计代价 $g(n)$ | 本次新增代价 $\Delta g$ |
| :---: | :---: | :---: |
| 0 | 0 | 0 |
| 1 | $\lambda_1$ | $\lambda_1$ |
| 2 | $2\lambda_1 + \lambda_2$ | $\lambda_1 + \lambda_2$ |
| 3 | $3\lambda_1 + 2\lambda_2$ | $\lambda_1 + \lambda_2$ |

每次正式修订的奖励扣减为 $-[g(n_{ki}^{\mathrm{new}}) - g(n_{ki}^{\mathrm{old}})]$。只在对应事件计入增量，不在后续每个解码动作反复扣除全部历史代价。  
它表达“不改最好；改一次有代价；超过一次需承担更高边际代价”。不能保证始终最多一次。如果确需严格最多一次，就必须另加硬约束，但这不是用户本轮选择。  
该项作为连续修订代价中的站位变更部分，不再重复叠加一份完全相同的次数惩罚。相对基准的最终站位偏离衡量结果，累计变更次数衡量过程，两者可以同时保留。

## 六、 效率与两层稳定性评价

### 6.1 相对原始基准的时间偏离
设 $S_{ki}^0$ 为原定开工时刻，$S_{ki}$ 为实际开工时刻：
$$D_{\mathrm{time}} = \sum_{k,i} \left( w_E [S_{ki}^0 - S_{ki}]_+ + w_L [S_{ki} - S_{ki}^0]_+ \right), \quad w_E, w_L > 0$$
提前和推迟均受惩罚；不要求权重相等。各飞机基准时刻固定，不按实际转站重置。另统计最终站位偏离与团队差异，形成基准偏离指标。

### 6.2 相邻两次正式修订之间的变化
*   对两份正式计划中都已存在且具有可比安排的同一“飞机—工序”记录，比较开工时刻、执行站位和工人团队。新进入视界的任务首次公布安排不能误计为对不存在的旧安排的修改。
*   已执行或已冻结任务不能修改；同一任务转移站位后仍应按其唯一身份追踪，不能因离开本站而漏掉变更记录。可按站位汇总，但新飞机进入站位不等于上一架飞机的计划被修改。
*   本阶段“同站位内相邻两次修改”按相邻正式计划修订解释。不同飞机执行同一道工序的团队连续性是另一指标，本阶段不自动加入目标。

### 6.3 总体目标结构
*   采用“生产绩效 ＋ 基准偏离 ＋ 连续修订代价”的结构，具体归一化和权重留待技术路线阶段确定。
*   生产绩效至少报告全体飞机累计完工延期及整批完工时间；基准偏离至少报告任务开工双向偏差、站位变化和团队变化。
*   最终执行结果的基准偏离与滚动决策时的预测偏离须分别记录，避免每次重规划都重复累计同一最终偏差。若通过逐步奖励实现，需要检查累计回报与目标统计的一致性。
*   软惩罚不能替代前序、空间、技能、工人不重叠、物料可用性或转站条件等硬约束。

### 6.4 避免滚动视界掩盖欠工
在视界末端为剩余任务计算后续代价，或接续统一的可行排程规则估计完成结果。评价整批任务的实际完成，**不允许仅通过把任务推到视界外获得较低目标值**。  
若沿用只生成尽早开工安排的解码器，则时间惩罚只能在其可生成方案范围内发挥作用；这不等于策略拥有任意插入等待的能力。是否增加主动等待属于后续算法设计，不改变已确认的完成后同步转站规则。

## 七、 贯序决策与运行流程

保留原有动作结构：
$$\text{飞机—工序} \longrightarrow \text{合法执行站位} \longrightarrow \text{该站位工人团队}$$
*   每架飞机的工序节点具有唯一身份，并携带实际位置、执行状态、基准安排及修订历史。
*   未来选队是计划，不代表工人从当前时刻起就被占用；实际资源占用从工序开工到完工。
*   运行流程建议为：**读取状态 $\rightarrow$ 固定不可修改部分 $\rightarrow$ 生成候选修订 $\rightarrow$ 检查整体可行性 $\rightarrow$ 发布采用方案 $\rightarrow$ 执行 $\rightarrow$ 满足全线条件后同步转站**。
*   无需在初版额外增加跨站调人模块。是否需要独立的等待或转站决策头，在后续技术路线中评估，不在本阶段预设。

## 八、 工作三的研究增量与方法候选

### 8.1 跨周期影响的具体来源
*   本站保留任务可能导致当前整线等待；改派至下一站位可能减少当前等待，却增加该飞机下一周期的任务负荷，挤占目标站位工时，影响下一次同步转站及届时在线的其他飞机。
*   因此，**不能继续用“工人跨站抢占导致后续架次人员饥饿”解释本模型**；本模型工人固定，其跨周期联系来自**任务负荷重分配、共同转站时刻、实际到料时间及已发布计划的继承**。

### 8.2 状态表征的具体对象
*   候选状态信息包括：后移任务集合、最晚合法站位、关键技能需求、未来站位负荷、预计整线瓶颈、基准偏离及历史正式改派次数。
*   可以探索预测未来若干周期的转站偏差、关键站位负荷或剩余后移任务等辅助目标。普通图RL本身已经学习表示，不能声称其仅利用即时奖励或完全不具备长程学习能力；拟研究的是显式任务相关辅助目标能否带来额外收益。

### 8.3 保留方法库，不提前锁定叠加结构
*   辅助预测、互模拟度量和原型方法均保留为候选。它们是可分别检验的路线，不预设必须依次叠加，也不预设均有效。
*   互模拟方法的保证取决于相应理论条件；原型方法的解释性价值不自动意味着调度性能或泛化改善。具体论文的方法定位应在逐篇阅读后确认，不能把事后解释方法直接描述为策略训练增益模块。

| 要检验的问题 | 对照设计 | 主要观察量 |
| :--- | :--- | :--- |
| **相邻工序改派是否有价值** | 禁止改派与允许相邻改派；其余信息和执行条件相同 | 累计延期、整批完工时间、基准偏离 |
| **多次后移是否必要** | 全程最多一次，与允许多次但重复更重罚 | 改派次数分布、至少两次改派的任务占比、生产绩效 |
| **重复惩罚能否减少反复修改** | 普通变更代价与包含重复额外代价 | 零次/一次/多次变更比例，收益与稳定性权衡 |
| **多周期协调是否优于局部修复** | 相同可见信息下，局部目标与滚动多周期评价 | 当前等待、后续瓶颈、全批次稳定性 |
| **新增表征目标是否有效** | 相同环境和动作空间的图RL基线与表征变体 | 性能、泛化、训练及推理成本 |

*   对照方法保持相同信息可见性、工艺可行集合与任务完成要求；尽量匹配参数量、训练预算和调参投入。
*   因研究假设不同而改变动作权限的实验，与仅改变算法的实验分别解释。
*   所有方法必须完成任务，不能把失败或残余任务从统计中删掉。报告多种子结果与不确定性，不预先承诺显著提升。

## 十三、 可直接用于开题的研究内容表述

> 针对物料扰动下多架飞机连续装配过程中任务站位重分配与同步转站之间的耦合关系，研究基于状态表征学习的动态协同调度方法。在继承初始基准计划与工人站位绑定的基础上，对允许调整的未开工工序进行相邻站位重分配和站内团队优化；各站位完成修订后分配的全部任务并满足工艺放行条件后，全线同步转站。通过联合评价当前周期等待、后续周期任务负荷、相对原始基准的双向时间偏差及连续计划修订代价，抑制不必要的工序移动与反复修改。对首次站位变更施加代价，对重复变更增加额外代价，使策略在保持工艺可行性的前提下尽量不移动工序或最多移动一次，并在必要时保留再次后移的调度空间。进一步探索面向后续负荷与转站后果的任务相关状态表征，并通过受控对照实验检验其对调度绩效与泛化能力的影响。
