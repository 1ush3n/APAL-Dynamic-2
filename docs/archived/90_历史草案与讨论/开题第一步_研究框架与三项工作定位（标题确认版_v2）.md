- 面向同型号飞机在同步脉动装配线上的重复生产，研究多资源耦合条件下的基准计划生成、物料扰动下的稳定性修复，以及面向扰动跨周期影响的多架次滚动协同决策。方法上由资源关系表示与联合决策，递进到基准及扰动条件化决策，再到受决策后果约束的任务相关表征学习。
- **学生身份**：同济大学电子与信息工程学院控制科学与工程专业研二硕士生，2026年9月升研二。
- **进度约束**：导师要求组织为三项研究工作。开题预计2026年10月中下旬，全部准备工作须在10月8日前完成；建议10月7日晚作为内部交付截止。
- **成果状态**：据用户确认，第一篇已录用CAC 2026；第二篇处于投稿准备/投稿阶段，拟投IEEE TSMC；两项研究均由用户独立完成。此处不将研究独立完成等同于单一论文署名。
- **模型统一**：两项研究均随排程逐步确定工人站位绑定。完工跨度定义统一以第二篇为准：$H=C_{\max}$，为周期模板跨度；基准固定后 $T_{\text{ref}}^0=C_{\max}(\pi^0)$。第一篇旧有“五倍节拍”文字不作为开题统一定义。
- **数据与仿真**：已有工艺数据支持同型号多架次展开，但第三项仍需定义飞机进入、物料供应及信息揭示等仿真机制；这不等于已有真实连续运行日志。
- **第三项定性**：第三项允许完整修改数学模型、算法和仿真引擎。解释性是次要目标，性能改善是核心要求。

### 2.1 工作一的研究定位
面向无外部扰动条件下的飞机脉动装配线，研究工序、站位和工人团队之间的联合决策。利用异构图表达工艺依赖与资源关系，通过自回归决策逐步构造完整调度动作，在前序、技能、人员互斥、站位容量和工人站位绑定等约束下生成可执行的基准计划。
本项重点是多资源联合建模与基准计划生成。自回归决策指后续选择以已经作出的选择为条件，不因多个动作阶段就称为“分层强化学习”。人员选择是联合动作的一部分；第二项进一步研究扰动与承诺继承条件下的人员调整，不需要从第一项中删除人员因素来制造两项工作的区别。

### 2.2 工作二的研究定位与标题核验
**定位表述**：面向物料到料延迟引起的周期计划失配，研究基于图网络的预测—反应式调度与人员分配优化。在基准计划生成的基础上，将基准安排、更新后的物料释放时间与冻结状态融入图表示，继承冻结任务和已有工人—站位绑定，联合优化可调整任务的作业安排及具体人员团队，在恢复效率与计划稳定性之间取得平衡。

#### （1）为什么能够称为“人员分配优化”
本轮核验依据为用户第二篇《英文版.pdf》，题名为 *Joint Scheduling and Workforce Allocation for Aircraft Pulsating Assembly Lines via Heterogeneous Graph Reinforcement Learning*。
| 核验维度 | 论文中的直接依据 | 对标题的支持 |
| :--- | :--- | :--- |
| **人员是否属于决策变量** | 第III节表I定义人员分配变量 $y_{iw}$ 与具体团队 $W_i$；第IV-A节联合动作包含工序、站位和团队 | 模型决定具体由谁执行任务，属于人员分配 |
| **人员选择是否影响生产结果** | 第III-B节式(1)中，作业时长 $D_i(W_i)$ 取决于被选工人的效率 | 人员选择会改变加工时长及后续资源占用，具有优化意义 |
| **是否满足人员适配约束** | 第III-B节式(5)—(7)约束团队人数、技能、站位专属和工人时间互斥 | 人员分配在明确的物理可行域内进行 |
| **扰动后是否仍有人员决策空间** | 第III-D节冻结集合继承原团队；可调整工序保留团队选择空间；既有站位绑定继承，仅原先未使用工人仍可未绑定 | 属于承诺约束下的人员重新分配，不是任意跨站调动 |
| **是否权衡人员调整代价** | 第III-D节式(13)纳入团队变更率 $R_{\text{team}}$，系数为0.3，同时考虑完工与其他计划偏离 | 人员安排既影响效率，也进入稳定性评价 |

**核验结论：可以采用“人员分配优化”**。工人团队是算法的决策变量，其选择影响时长、资源可用性和稳定性目标；无需另设一个独立的“人员目标函数”，也能构成联合调度中的人员分配优化。“优化”不表示已证明全局最优，也不表示每个扰动场景均优于所有对照。
每道工序的团队人数 $q_i$ 是给定参数，优化的是具体成员及其可行分配。现有工作不据此主张优化企业总用工人数、岗位编制、招聘培训或任意跨站调配。“人员配置”可以有宽泛的资源配置含义，但若不作限定容易扩大研究范围，故正式名称统一采用用户选中的“人员分配优化”。

#### （2）为什么能够称为“预测—反应式调度”
经典重调度框架将预测—反应式调度概括为先形成生产计划，再根据扰动或事件更新计划；一次扰动后的计划修订也可属于这一框架（Vieira et al., 2003, 第5.2节）。
本研究对应过程为：先生成基准周期模板，在物料延迟信息揭示后，以冻结边界和既有绑定限制调整范围，再修复后续可调整计划。“预测”在此指预先制定计划，不要求新增物料预测网络。当前更新后的物料释放时间在重调度触发时已知，不应改写为已具备到料时间预测能力。
第二项可以沿用第一项的基准生成方法，新增贡献集中在基准与扰动信息增强、冻结承诺与绑定继承、人员分配与稳定性修复。不能将整套基准调度架构重复计为第二项独有贡献。

### 2.3 工作三的研究定位及与工作二的区别
**定位表述**：面向多架飞机连续装配过程中扰动影响的跨架次传播，研究基于状态表征学习的动态协同调度方法。显式描述不同飞机的实际站位、任务进度和物料条件，在共享物理资源、同步脉动与跨周期衔接约束下，学习与即时收益及后续状态演化相关的表示，支持多架次计划的滚动联合调整。
- 本课题中“多架次协同调度”的操作性含义是：统筹同一产线上不同在制飞机的任务及跨周期衔接，在调整当前任务时考虑其他飞机和未来周期的影响。协同关系必须进入模型、决策范围和整体评价；仅重复一份固定模板不足以验证此项贡献。
- 工作二重点是计划层面的周期模板修复；工作三拟处理带飞机身份、实际执行状态与跨周期影响的连续运行问题。新增表征学习应通过即时收益和后续演化等训练约束明确其增量，不能仅把已有图编码器更名为“状态表征学习”。不将人工语义标签、聚类、双模拟保证或可解释性列为已经确定的必要组件。

| :--- | :--- | :--- | :--- |

## 3. 第三项的核心研究假设与范围

- **研究假设**：对同型号飞机的连续脉动生产，若潜在状态表示保留了调度行为对即时损失、资源后续可用性和跨周期运行的影响，则可能改善滚动协同策略的决策质量与跨情境适应能力。该假设必须通过同一多架次环境中的受控比较检验。
- **情境不要求预先人工分类、命名或赋予人类语义**。首先学习连续任务相关表示，再验证是否需要离散聚合、原型或软分组。奖励和转移产生训练信号，因此更准确的表述是“无需人工情境标签的表征学习”，而非完全没有监督信号。
- **拟优先验证方案**：基础滚动图强化学习；增加决策后果约束但不聚类；增加聚类/原型（若采用）；普通特征聚类对照。使用相同环境、信息可见性和相近训练/计算预算，以区分环境扩展、网络容量、后果表征和聚合机制的收益。

### 边界与默认设定：
1. 同型号、共享工艺模板，但每架飞机有独立的任务完成状态、物料条件和实际站位；工人是产线共享的物理资源，不能随飞机复制。
2. 同步脉动、飞机单站占用、前序、容量、技能与工人互斥为硬约束。已开工工序保持非抢占。任务变更惩罚主要针对尚未执行的计划分配。
3. 工序改站仅在该架飞机实际到达可执行站位、满足前序和资源约束时允许；飞机不能为补做工序逆向返回或同时跨站执行。暂保留既有工人站位绑定，跨周期重新配置不作为首版必备任务。
4. 先研究有持续时间和恢复时刻的物料短缺。未来真实到料结果仅在设定的揭示时刻进入策略；仿真器已生成的未来随机量不自动对策略可见。初版可在扰动揭示时给出恢复时间，后续再研究预测误差。
5. 其他扰动作为扩展测试。工人缺勤影响共享资源供给，工时变化影响占用区间，执行中故障可能涉及中断；不能仅因均造成延迟就视为同一种释放时间变化。
6. 物料恢复不保证累计延迟归零。分别评估继续传播是否受抑制、剩余延迟大小，以及有可压缩周期/资源余量时能否追赶基准；不保证所有情境都能恢复原始绝对时刻。
7. 滚动优化可以更新内部计划，但稳定性评价保留原始基准，避免不断更换参照使偏离看似消失；同时可另报相邻两次已发布计划之间的变更。
8. 首版固定一组主要权重并报告各原始指标，辅以权重敏感性分析。若未来要求单一模型适应多组权重，应显式条件化偏好或保留分量代价信息，避免加权和抵消造成不合理聚合。

## 4. 方法借鉴与尚待核验的增量
- Zhang 等的 DBC 研究使用奖励差异与后继分布差异学习面向控制的表示，并区分严格动作条件下的双模拟定义与用于学习的策略相关近似。它提供方法启发，不自动赋予本课题最优性或策略保持保证。[论文全文](https://arxiv.org/html/2006.10742v2)
- 本课题需要专门解决：变规模图中动作如何对应、可行行动集合差异如何保留、物理恢复时长如何进入后果描述、不同目标权重下何种信息不能被合并。当前策略下收益相似，不等于其他候选动作的优劣排序也相同。不能把工序编号一致当作动作语义一致。
- **新颖性状态**：前两项已有成果与第三项拟研究内容的归属已建立；第三项方法增量暂定，须在下一步对照最接近的图强化学习、任务相关表征、行为相似性和滚动恢复文献核验。与组员研究的区别应落在研究问题、方法和评价贡献，而不是“首次考虑多架飞机”。
