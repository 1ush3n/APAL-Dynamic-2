## 一、阶段结论与确认标题

本阶段没有必须继续向用户追问、才能形成开题模型的问题。已明确工作三的实际跨周期联系：未开工工序经合法改派后，改变后续站位的任务负荷；后续周期的整线同步转站可能因此受到影响。固定工人站位仍可保留。

| 层级 | 已确认名称 |
|---|---|
| 总体课题 | 基于图表示学习与强化学习的飞机脉动装配线调度方法研究 |
| 工作一 | 基于异构图与自回归决策的多资源联合调度 |
| 工作二 | 基于图网络的预测—反应式调度与人员分配优化 |
| 工作三 | 基于状态表征学习的多架次飞机装配动态协同调度 |

三项工作的衔接定位如下：

1. 工作一：生成无扰动条件下的基准模板，联合安排工序、站位与工人团队。
2. 工作二：沿用基准计划，研究物料扰动下的预测—反应式调度与人员分配，继承已有冻结和绑定约束。
3. 工作三：以多架实际飞机连续执行为对象，显式维护每架飞机的状态，统筹工序站位重分配、后续任务负荷和连续计划修订。

工作三的研究问题可表述为：

> 在固定工人站位和同步脉动约束下，如何通过受约束的工序站位重分配与站内团队优化，权衡当前周期等待、后续周期任务负荷及全生产过程的计划稳定性？任务相关状态表征能否改善这种跨周期决策？

这里的“协同”指不同架次装配计划之间的协调，不要求采用多智能体。

## 二、最终运行规则

| 事项 | 本阶段确认的设定 |
|---|---|
| 基准计划 | 首先生成无扰动基准模板，再按原定投产节奏展开为各架飞机的基准计划 |
| 基准是否重置 | 原模板不重写；时间比较采用原模板周期内偏移与实际周期内偏移，允许整周期平移 |
| 工人站位 | 继承初始安排，在工作三指定生产批次内固定；暂不考虑跨站调人 |
| 团队调整 | 对允许调整的未开工任务，可在执行站位的固定工人中重新选队 |
| 调整耗时 | 初版不单独建模团队调整耗时，以变更惩罚表达调整代价；工序本身的团队相关作业时长仍正常计算 |
| 可改派工序 | 未完成、未开工、未冻结，且满足全部工艺与执行条件的工序 |
| 单次后移范围 | 对当前站位待处理任务，保留当前站位或改派至紧邻下一站位 |
| 多次后移 | 必要时允许再次后移；不设置“全程最多一次”的统一硬上限 |
| 少移动的偏好 | 第一次正式站位变更就施加惩罚，第二次及以后增加额外惩罚，鼓励不移动或最多移动一次 |
| 最远执行位置 | 由合法站位、前后序关系、转站必完节点、设备及人员能力限定，不能无限后移 |
| 转站方式 | 所有站位完成修订后分配在本站的全部任务，并满足不可更改的转站条件后，整线同步转站 |
| 时间目标 | 相对各自周期起点的开工位置提前或推迟均受罚，暂用同一系数；绝对日历整体平移不计此项 |
| 飞机物理位置 | 每架飞机同时只在一个站位；不能在未到达的站位提前执行工序 |
| 作业连续性 | 已开工工序不跨站中断后续做，转站前完成；已完成任务不重新安排 |
| 未来信息 | 决策只使用当时已知信息；不得读取仿真器未揭示的真实未来扰动 |

“尽量最多移动一次”是优化偏好，不是硬约束，也不是保证训练结果必然满足的性质。

## 三、明确区分三份计划与实际状态

### 3.1 原始基准计划

记原始基准为 \(P^0\)。每架飞机的每道工序有固定的基准开工时刻、基准站位和基准团队。

同一模板按原投产时刻展开后保留原始绝对日历。当前确认的稳定性目标比较周期内开工位置，采用各自真实周期起点；不在扰动或修订发生时任意重置。绝对交付延迟另行记录，不作为已确认的主要时间偏差惩罚。

### 3.2 当前已发布计划

记第 \(r\) 次正式修订的计划为 \(P^r\)。它是当前已发布安排及有效预约的记录，也是下次衡量“又改了多少”的参照；不要求含完整未来排程。后移分支可暂只发布目标站位。

飞机A的任务改派不自动修改其他飞机的模板。其他飞机是否修订，须根据各自执行状态和整体目标决定。

### 3.3 实际执行状态

持续记录飞机位置、已完成工序、在制工序、未开工工序、实际资源占用、已揭示的开工可用时刻以及历史正式修订记录。

网络内部试算方案不直接改变执行状态，不计入现场计划修改次数。

## 四、工序后移与同步转站的准确含义

### 4.1 必须先改派，再按新任务集合执行

例如，飞机A在站位2的任务集合为 \(\{a,b,c\}\)。工序 \(c\) 尚未开工且受到工序延迟开工（开工可用性延迟）影响，允许在站位3执行。

- 若保留原计划，站位2必须完成 \(a,b,c\)，才能与其他站位一起转站。
- 若正式将 \(c\) 改派到站位3，站位2当前任务变为 \(\{a,b\}\)，站位3未来任务中增加 \(c\)。只有本站 \(a,b\) 及其他站位当前任务全部完成、且各项转站条件满足后，才同步转站。

工序 \(c\) 没有被删除或视为完成，它仍需在飞机实际到达目标站位后执行。不得到原定转站时刻就自动跳过或后移未完成任务。

### 4.2 不可通过改派绕过真实转站条件

若某工序必须在转站前完成，或者其后继任务被固定在本站，就不能仅通过改变该工序的站位标签使整线获得转站资格。

改派必须保留符合工艺、站位与技能要求的后续执行可能性；不要求当场求出完整未来计划。若无法构造可行改派方案，则沿用可行安排并等待开工条件或资源满足，接受延期；若已知条件导致任务本身无法完成，应报告不可行，不能以惩罚替代合法性。

### 4.3 当前站位与下一站位的动作掩码

对于飞机 \(k\) 当前位于站位 \(s_k\) 时，属于当前局部修复范围的工序 \(i\)：

\[
\mathcal S_{ki}^{\mathrm{candidate}}
=\{s_k,s_k+1\}\cap\mathcal S_{ki}^{\mathrm{feasible}}.
\]

其中可行集合检查：工艺站位资格、冻结状态、前后序关系、转站必完要求、目标站位设备与空间、固定工人的技能及团队可组建性。

该局部掩码不用于强行把全部未来工序压到当前和下一站位。原本就在更后站位的未来任务继续保留其未来安排。末站不存在下一站位，所有离线前必须完成的任务均须完成。

未来站位的可行性应按其预计执行区间检查，不能仅因该站位工人当前正在服务另一架飞机，就永久排除未来安排。

### 4.4 多次后移

可以在后续实际周期中再次修订，但每次都重新检查全部约束。例如由站位2改至3，飞机实际到达3后，必要且合法时再改至4。

同一物理周期内反复调用修复器，不应绕过“当前站位和下一站位”的限制，把工序连续推到多个更远站位。

合法站位集合可能不连续。若下一站位不合法，本方案不允许直接跨过它跳到更远站位；这是本研究的相邻调整限制。

### 4.5 转站时间

原定转站时间作为固定参考。实际转站依据各站位任务的实际完成状态和转站条件决定，允许提前或延期。

若暂不单独计算转站耗时，且无额外转站时间窗，在一个任务分配已确定、转站条件均满足的周期内，下一次转站由最后一个站位完成当前任务的时刻触发。实现时还应处理当前时刻、空站及空任务集合，不能使时间倒退。

若后续实际数据要求运输耗时或固定转站时间窗，应明确加入约束；本阶段不额外引入这些机制。

## 五、站位变更奖励：第一次就惩罚，重复变更更重

### 5.1 次数的定义

令 \(n_{ki}\) 表示同一架飞机、同一道工序在正式发布计划中的累计执行站位变更次数。保持站位不变不增加次数；改队不算站位变更，另计团队变化。

若在飞机尚未转站前依法撤回一次改派，且该撤回被正式发布，也应计为一次站位变更，避免反复修改被漏计。此处统计的是计划改派，不是人员或已完成工序的物理搬运。

### 5.2 建议实现形式

采用下列分段代价作为后续实现的起点，具体数值尚未确认：

\[
g(n)=\lambda_1 n+\lambda_2[n-1]_+,
\qquad \lambda_1>0,\;\lambda_2>0.
\]

| 累计变更次数 | 累计代价 | 本次新增代价 |
|---|---|---|
| 0 | 0 | 0 |
| 1 | \(\lambda_1\) | \(\lambda_1\) |
| 2 | \(2\lambda_1+\lambda_2\) | \(\lambda_1+\lambda_2\) |
| 3 | \(3\lambda_1+2\lambda_2\) | \(\lambda_1+\lambda_2\) |

每次正式修订的奖励扣减为 \(-[g(n_{ki}^{\mathrm{new}})-g(n_{ki}^{\mathrm{old}})]\)。只在对应事件计入增量，不在后续每个解码动作反复扣除全部历史代价。

它表达“不改最好；改一次有代价；超过一次需承担更高边际代价”。不能保证始终最多一次。如果确需严格最多一次，就必须另加硬约束，但这不是用户本轮选择。

该项作为连续修订代价中的站位变更部分，不再重复叠加一份完全相同的次数惩罚。相对基准的最终站位偏离可单报诊断指标；累计正式改站次数进入目标函数，二者不能作为同一成本重复收取。

## 六、效率与两层稳定性评价

### 6.1 相对原模板的周期内开工偏差

记原开工时刻为 $S_i^0$、所属原周期起点为 $P_{q_i^0-1}^0$，实际开工时刻为 $S_i$、所属实际周期起点为 $P_{q_i-1}$。定义

$$b_i^0=S_i^0-P_{q_i^0-1}^0,\quad b_i=S_i-P_{q_i-1},\quad D_{time}=\sum_i|b_i-b_i^0|/H_0.$$

提前和推迟暂用相同系数。周期整体平移不计入此项；改站与团队变化单独计费。原基准数据不被重写。已改站任务的偏移参照建议沿用原任务偏移，实施时用小案例核对，不能借改站清空代价。

### 6.2 相邻两次正式修订之间的变化

对两份正式计划中都已存在且具有可比安排的同一“飞机—工序”记录，比较周期内开工位置、执行站位和工人团队。初始基准是正式参照；未曾存在的字段不与虚构旧值比较。后移后尚未定队不等于全部换人。

已执行或已冻结任务不能修改；同一任务转移站位后仍应按其唯一身份追踪，不能因离开本站而漏掉变更记录。可按站位汇总，但新飞机进入站位不等于上一架飞机的计划被修改。

本阶段“同站位内相邻两次修改”按相邻正式计划修订解释。不同飞机执行同一道工序的团队连续性是另一指标，本阶段不自动加入目标。

### 6.3 真实目标与计账

实际节拍 $H_q=P_q-P_{q-1}$，固定基准节拍为 $H_0$，效率主项为 $\sum_q[H_q-H_0]_+/H_0$。连续周期12、10小时，相对10小时基准的超期为2、0小时；不把持续日历偏移重复罚为2、2。

实际开工时记录一次最终基准时间位置与团队差异；最终站位偏离另报诊断指标，正式改站的次数代价在修订时按增量计入。固定人数m的替换比例为 $1-|W\cap W^0|/m$。正式修订时记录相邻安排的变化，实际脉动时结算本周期超期。最终不重复全额计费。冻结、前序、技能、资源和放行条件仍为硬约束。

基础奖励是每条动作转移中实际新增代价的负值；其上增加一致的势函数差分，不用预测值代替实际节拍。具体公式与版本条件见方法设计阶段确认稿。

### 6.4 结束条件与等待

统一决策五个站位，连续执行至指定批次实际完成，不设置强制两周期详细规划。全部预约完毕不等于生产完成，后移任务不得从最终统计消失。

工人忙碌、已知开工下界尚未到达通过未来预约处理；选队后可选择尽早执行，或添加“实际周期起点＋原模板开工偏移”的下界。已晚于该目标不额外等待。主动对齐需要正确的资源日历，不能将等待期视为实际占用。

## 七、序贯决策与执行流程

一个执行环境内依次观察、选动作、登记或修改预约、处理生产事件、返回下一决策。无可行动作时推进至下一相关事件；有决策时可保持同一物理时刻。无需独立虚拟层。

- 当前站执行：飞机—工序→当前站位→站内团队→二元对齐。
- 合法后移：飞机—工序→紧邻下一站位，截断选队与对齐；实际进入下一站后再和原有任务统一安排。

后移分支PPO概率只包含激活的选择，不能补虚假团队概率。已预约但未开工可修改，实际已开工和已完成硬冻结，不添加未来承诺窗口或人为优先级。任务完工、达到已揭示开工下界可解锁派工，扰动与实际脉动是重要调整机会。所有奖励随step返回，远期影响由回报学习。

## 八、工作三的研究增量与方法候选

### 8.1 跨周期影响的具体来源

本站保留任务可能导致当前整线等待；改派至下一站位可能减少当前等待，却增加该飞机下一周期的任务负荷，挤占目标站位工时，影响下一次同步转站及届时在线的其他飞机。

因此，不能继续用“工人跨站抢占导致后续架次人员饥饿”解释本模型；本模型工人固定，其跨周期联系来自任务负荷重分配、共同转站时刻、已揭示的工序开工下界及已发布计划的继承。

### 8.2 状态表征的具体对象

候选状态信息包括：后移任务集合、最晚合法站位、关键技能需求、未来站位负荷、预计整线瓶颈、基准偏离及历史正式改派次数。

已选择以实际当前周期转站时刻监督图表征对启发式时间估计的修正，修正时间进入动作头与势函数；其他跨度预测保留为扩展。普通图RL本身已经学习表示，不能声称其仅利用即时奖励或完全不具备长程学习能力；拟研究的是显式任务相关辅助目标能否带来额外收益。

### 8.3 主路线已选，保留方法库

主路线为启发式时间残差辅助预测，Critic仍学习综合回报。互模拟度量和原型保留为扩展，不要求与主路线叠加，也不预设有效。

互模拟方法的保证取决于相应理论条件；原型方法的解释性价值不自动意味着调度性能或泛化改善。具体论文的方法定位应在逐篇阅读后确认，不能把事后解释方法直接描述为策略训练增益模块。

## 十三、可直接用于开题的研究内容表述

针对工序延迟开工（开工可用性延迟）下多架飞机连续装配中工序后移与同步转站的关系，研究基于状态表征学习的动态协同调度方法。在继承初始基准计划与工人站位绑定的基础上，对允许调整的未开工工序进行相邻站位重分配和站内团队优化；各站位完成修订后分配的全部任务并满足工艺放行条件后，全线同步转站。状态记录当前与后续周期任务负荷；目标按实际转站结算周期超期、按实际开工结算周期内位置与团队偏差、按正式修订结算团队/时间变化和改站代价。当前等待及后续负荷通过实际执行影响整条轨迹的周期超期，另用周期层记录核查。对首次站位变更施加代价，对重复变更增加额外代价，以成本引导策略减少改站和重复修改，同时保留满足硬约束时再次后移的决策空间；不能承诺最多移动一次。进一步通过实际转站时间监督学习启发式时间残差，将修正时间用于动作辅助输入与势函数，同时由Critic学习综合回报，并在相同事件、环境和训练预算下比较无时间模块的图策略C、完整方法D及仅辅助监督E、加入修正时间输入F、加入预测势函数G，分别检验残差误差、动作输入和势函数的作用；未见扰动实例上的表现须单报。
