## 2. 当前实现中的推进路径

| 路径 | 触发条件与结果 | 策略概率归属 |
|---|---|---|
| 显式推进 `ADVANCE_TO_NEXT_EVENT` | 存在可修订预约时，策略可结束当前安排轮并推进到下一有效事件；可以与READY工序并存 | 是独立策略选择；其推进门控概率进入本次动作及PPO重放 |
| 完全相同预约重交后推进 | 策略重复提交与当前预约完全相同的留站安排；环境不产生修订，不收修订费，随后在同一step内推进一个下一有效事件 | PPO概率属于被选择的重复留站动作；环境确定性推进不产生第二动作或第二项概率 |
| 无合法调度候选时推进 | Actor输出唯一的强制推进动作，推进至下一有效事件；若无有效未来事件且批次未完成，则以`deadlock`失败终止 | 强制推进的策略log-prob为0，不增加策略熵或动作概率 |
| 普通调度动作后自动推进 | 留站/后移动作结束后已无合法调度候选；环境在同一step内推进到下一决策状态 | 不为自动推进另采样动作或概率 |

## 3. READY工序的机会变化

完全相同预约重交后的自动推进也适用于“预约任务可修订、另有READY工序”的混合候选状态。环境推进前，READY工序仍是合法候选；推进后它不会被删除，仍可能继续决策，但策略失去了在原物理时刻先行安排它的机会。这是当前动作语义的重要边界，不能只用“READY任务没有消失”来描述。

显式推进和重复预约重交均调用推进至下一有效事件的环境路径，因此可能从相同现场到达同一后继事件状态，但对应的PPO动作不同：一个是推进门控选择，另一个是具体工序的留站重交。本轮没有做两路径从完全相同快照出发的状态/奖励逐字段等价比较，也没有完成训练报告中的路径计数核验；这两项保留为后续独立验证，不列为本补充稿已通过结果。

## 4. 奖励、PPO样本与日志

- 环境原始奖励为本step累计真实费用增量的相反数：`reward = -(cost_after - cost_before)`。推进期间发生的费用仍属于触发推进的step。
- 显式推进是被策略采样的动作，按该动作概率重放。
- 重复预约重交仍是一个留站动作。若安排完全未变，则不新增修订费；随后推进是该动作的确定性环境后果，不另计推进概率。
- 无候选强制推进的策略log-prob为0；普通调度动作后的环境自动推进也不另造策略样本。
- 环境即时返回的信息可区分显式推进与重复预约推进：前者的动作分支为`ADVANCE_TO_NEXT_EVENT`；后者是留站分支，并返回`revision_changed=false`及`advanced=true`。本轮小例检查了这些字段及该步奖励守恒。训练汇总目前未单独统计不同推进路径的次数；不能据此宣称正式实验日志已充分比较两条路径。
