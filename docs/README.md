# APAL-Dynamic-2 当前文档导航

当前生产实现统一位于 `apal/`，命令从仓库根运行；先按仓库说明进行不安装依赖的editable登记。当前代码入口与方法边界从以下两处读取：

1. [仓库说明](../README.md)：三项研究的正式训练、评估入口与运行目录。
2. [工作三迁移与验证记录](work3_query_migration.md)：QUERY 的分层融合、准确条件查询、联合动作、PPO重放及已实际执行的验证。按文末日期章节读取最新结果，历史测试数量不累加为本轮结果。

工作三正式路径使用 `conf/work3/train_query.yaml`，不创建独立时间预测头、时间标签缓存或预测势函数。旧 B/C/D/E/F/G、时间预测与旧研究扩展保留既有含义，仅用于相应历史入口。

[历史资料位置与恢复方法](history.md)记录项目外普通资料目录、逐文件清单及校验方法。开题正文、导师批注、文献、PPT、图稿、旧审计和旧实验报告已按原相对结构保存到该目录；2026年10月的v3及时间预测设计属于历史依据，不再称为当前方法的唯一基准。现行论文要求以用户确认的最新版正文为准，代码报告仅说明实现与验证事实。

[本轮逐项路径映射](directory_migration.csv)记录源码、配置、夹具与历史材料的新位置。当前工作三事件与重放回归分别位于 `tests/work3/test_transfer_semantics.py`、`test_same_timestamp_events.py`、`test_worker_mask_replay.py`；迁移报告中的旧测试名和命令保留为当时运行记录。

[当前数据入口](data.md)说明三项研究的模板、训练池、R5清单与工作三基准；[目录维护与本轮验收](maintenance.md)记录命名规则、运行目录、实际检查及剩余边界。

数据、场景、训练划分和回归夹具仍随代码维护；资料整理不改变APAL物理规则、PPO算法或检查点输入语义。

[研究成果索引](research.md)记录用户提供的最优示例准备成果及未验证边界，不代表本轮运行结论。当前确认Word/PPT/图源本轮按用户要求跳过回迁，未把本地旧稿放进当前proposal。

[示例预训练与PPO有限对照](pretrain_pilot_report.md)记录2026-11-17随后实际实施的真实扰动补验、52个有证书构造例、两种子GPU学习及留出结果。该试点有工程通路证据，未观察到预训练的总体收益；[逐实例结果](pretrain_pilot_results.csv)保留成功、持平及退化。
