2. [工作三迁移与验证记录](work3_query_migration.md)：QUERY 的分层融合、准确条件查询、联合动作、PPO重放及已实际执行的验证。按文末日期章节读取最新结果，历史测试数量不累加为本轮结果。

[本轮逐项路径映射](directory_migration.csv)记录源码、配置、夹具与历史材料的新位置。当前工作三事件与重放回归分别位于 `tests/work3/test_transfer_semantics.py`、`test_same_timestamp_events.py`、`test_worker_mask_replay.py`；迁移报告中的旧测试名和命令保留为当时运行记录。

[当前数据入口](data.md)说明三项研究的模板、训练池、R5清单与工作三基准；[目录维护与本轮验收](maintenance.md)记录命名规则、运行目录、实际检查及剩余边界。
