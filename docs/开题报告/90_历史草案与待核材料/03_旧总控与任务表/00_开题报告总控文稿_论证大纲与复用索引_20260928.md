### 3.3 统一模型边界、符号及三项接口

设工序集合为\(\mathcal O\)，站位为\(\mathcal M\)，工人为\(\mathcal W\)，工艺有向无环图为\(E^+\)。工序\(i\)的站位\(m_i\)、团队\(W_i\)、开工\(B_i\)、完工\(C_i\)构成计划；技能要求、团队人数、前后序、工人互斥与首次分配后站位绑定构成共同约束背景；站位空间／并行容量按各项工作及其数据分别界定，工作三不由未使用的部位容量列推导空间约束，已有明确并行上限注明为环境配置。团队影响工时，不能把“人员分配”说成仅决定人数。工作二论文中团队相关工时可用\(D_i(W_i)=p_i^{std}q_i/(\rho^{q_i-1}\sum_{w\in W_i}\eta_w)\)说明，其中\(q_i\)为所需人数、\(\eta_w\)为效率、\(\rho\)为协作折减系数；这是该论文的模型形式，不推广为所有制造现场的物理定律。

**工作三旧账本目标的历史接口（9月28日默认 \(\texttt{normalize\_by\_n=True}\)）**：令\(N\)为固定的工序实例数，\(H_0\)为不随扰动重置的基准周期，\(S_{ki}\)为实际开工、\(P_{q-1}\)为其实际周期起点，\(b_{ki}=S_{ki}-P_{q-1}\)，\(b_{ki}^0\)为原模板相应周期内偏移，\(m_{ki}\)为团队规定人数。则

\[
\begin{aligned}
J_H&=\sum_q [H_q-H_0]_+/H_0,\\
D_T&=\frac1N\sum_{ki}|b_{ki}-b_{ki}^0|/H_0,\\
D_W&=\frac1N\sum_{ki}\left(1-\frac{|W_{ki}\cap W_{ki}^0|}{m_{ki}}\right),\\
G&=\sum_{ki}g(n_{ki}),\quad g(n)=\lambda_1 n+\lambda_2[n-1]_+,\\
R_T&=\frac1N\sum_{r,ki}\frac{|b_{ki}^{r}-b_{ki}^{r-1}|}{H_0},\\
R_W&=\frac1N\sum_{r,ki}\left(1-\frac{|W_{ki}^{r}\cap W_{ki}^{r-1}|}{m_{ki}}\right),\\
J_{total}&=w_hJ_H+w_tD_T+w_wD_W+w_pG+w_{RT}R_T+w_{RW}R_W.
\end{aligned}
\]

这里\(J_H\)按每次实际转站结算超期，五站只取决定转站的全线节拍，不逐站加总；\(D_T\)比较周期内位置，整周期平移不自动计罚；\(D_W\)比较具体成员，换一人与换三人不同；\(G\)第一次正式改站就计罚，重复改站额外计罚，**不是“最多只许改一次”**；旧接口\(R_T,R_W\)曾比较相邻正式发布字段；其删除、归零或合法计账口径尚待核对，不能为了保留它们重新开放决定修改，临时未选团队不视为全队撤换。\(G\)在当前配置下不除以\(N\)，不得在正文偷偷替它归一化；若未来关闭\(\texttt{normalize\_by\_n}\)，必须同步改写上述带\(1/N\)的口径。**站位终局偏离可以单报诊断指标，当前已确认目标中不另加独立\(D_{station}\)权重。**

工作三的方法增量围绕：①多架次真实执行、同步脉动与无连带迁移相邻后移；②复用完整图并按飞机／站位／整线及当前／下一周期组织摘要；③以两项实际时间后果监督共享表示，并按网络方案B连接预测输入和当前势函数。它们是待检验的组合机制，不能只将已有GNN改名或将版本管理单独称为已证明的算法创新。

## 4. 三项工作如何连成一篇开题报告

| 衔接问题 | 精确表达 | 容易产生的误读及修正 |
|---|---|---|
| 一→二 | 工作一统一同构表示对不同关系的区分仍需加强，且无扰动条件未覆盖释放延迟后的计划调整；工作二研究异构图联合调度与动态重调度。 | 不以工作一提供基准排程代替不足论证；不称工作一没有人员，也不称同构图不能满足硬约束。 |
| 二→三 | 多架次进度共同决定同步脉动，局部延迟可能影响其他飞机与后续周期；工作三据此学习事件的分层时间后果，支持实际执行中的任务统筹。 | “工作二完全没有多架次”不准确；固定模板可稳态展开，但不模拟受扰切换的在制动态。 |
| 表征递进 | 同构图静态联合决策→基准／扰动条件化异构图修复→分层融合与当前／下一周期后果监督的语义增强图。 | “工作三首次使用GNN/首次学习表征”错误；其新增学习目标和作用路径才是增量。 |
| 稳定性递进 | 工作二相对一个基准模板的开工、站位及团队变化；工作三记录不可撤回决定及跨周期合法后移，用实际周期内位置比较；旧过程修订项需按9月30日规则重新核对。 | 两项工作的复合指标分母、事件时机和站位变化定义不同，不把\(S\)与\(J_{total}\)直接比较数值。 |

**用户确认的衔接正文底稿：**

本课题围绕飞机脉动装配线的工序排序、站位分配与人员分配，按照“无扰动静态调度—扰动下动态调度—多架次协同动态调度”逐步展开，并相应研究同构图、异构图及语义增强图网络的状态表示方法。

工作一首先面向无扰动条件下的静态调度问题，采用同构图统一组织工艺与资源信息，通过自回归策略联合进行工序排序、站位分配和人员分配，构造可行排程。在此基础上，对工艺前序、技能匹配和资源安排等不同关系的针对性处理仍需加强，且无扰动条件下的研究尚未覆盖工序延迟开工后的计划调整。因此，工作二引入异构图，分别组织不同实体及关系的信息，并研究工序延迟开工扰动下兼顾完工时间与计划稳定性的动态调度。

工作二重点研究受扰周期计划的修复，尚需进一步考虑不同在制飞机在实际执行中的相互影响。在多架次连续生产中，各站位承载不同飞机，其任务进度共同决定全线同步脉动的时刻；局部延迟还可能影响其他飞机的转站与后续周期安排。因此，工作三在异构图表示基础上引入事件与后果语义，在工序／飞机、站位和整线层面预测当前及紧邻下一周期的时间后果，将现场状态进一步转化为对全线运行影响的理解，为多架次协同动态调度提供依据。

**研究技术路线按不足及回应组织**：工作一建立同构图静态联合调度，关系区分与扰动响应的边界引出工作二异构图联合调度和动态重调度；工作二模板层结果未覆盖受扰切换中的实际在制过程，进一步引出工作三的多架次执行、同步转站与跨周期后果语义。三项输出分别为基准模板、修复模板及实际轨迹；产物参照、已有计划与权重迁移分别放在模型或实现说明，不作为研究递进主线。
