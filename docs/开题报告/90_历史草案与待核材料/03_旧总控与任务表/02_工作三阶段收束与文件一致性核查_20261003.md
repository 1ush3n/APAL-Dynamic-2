## 3. 已统一的首版规则

| 方面 | 统一口径 |
|---|---|
| 执行 | 一个真实事件驱动环境；完整决定提交不可撤回，预约只可被动顺延；已开工非抢占 |
| 脉动与投产 | 实际全部站位首次就绪后同步转站；有待投产飞机时在该实际时刻进入一号站；首版无就绪反复变化 |
| 扰动 | 发生前不可见，发生后知道准确开工下界／持续时间；有效实际开工与扰动严格同刻时，开工优先 |
| 数据与图 | 现有README与完整DAG为依据；完整图编码，虚拟依赖正确保留；物理工作量、任务数与动作排除虚拟节点 |
| 任务集 | 当前飞机与下一次到站飞机的任务分开；未完读出、动作候选各有用途，已预约／运行仍属于未完任务 |
| 后移 | 只允许不会迫使其他任务换站的单工序相邻后移；统一分支掩码；不同实际阶段可再次合法后移，重复代价更高 |
| 分层 | 工序／飞机—站位当前／下一—整线，首版MLP；动态事实按事件更新，每次完整决策重算神经表示 |
| 语义目标 | 当前启发式转站残差＋紧邻下一周期各站有符号就绪偏差；实际结果监督，不是动作因果收益或最优工期 |
| 网络B | 完整轨迹开始复制完整预测路径，轨迹内权重固定但状态动态；在线Actor共享表示与辅助头继续学习 |
| PPO | 保存历史输入、当时外部预测值、版本与条件分支概率；不以新预测值替换旧输入，不给未激活头造概率 |
| 标签 | 逐决策保留可复原历史状态，两项标签分开按实际事件回填；待结算不填零，跨采样段保留；近期已结算样本辅助训练 |
| 费用与解释 | 当前预测用于既有势函数，下一向量不另加风险罚；旧R_T、R_W单列待核对；首版解释预测时间结果 |

## 5. 保留的未定事项

容量、样本年龄、训练更新次数、网络宽度、损失／目标权重、场景数等继续作为实施与验证参数。R_T、R_W在不可撤回决定下的最终删除、归零或合法计账处理未由本轮选择。全套消融交叉配置、改站任务的相对对齐细节、资源区间搜索和完整同刻事件顺序仍需后续实施核对；当前不为这些事项重开工作三讨论。

工作三性能、泛化、新颖性、原因解释均未由本轮得到证明。当前开题可以完整说明问题、已选技术路线、对应验证和风险；不能把旧接口烟测写为完整方法效果。外部文献及已有成果数字进入正文前按相应原文／论文图表核对。

## 6. 接下来怎样构思开题报告

先围绕一个总问题组织：在同步脉动与多资源约束下，怎样从生成可执行基准计划，推进到受扰时保护既有承诺，再推进到多架次实际执行中的跨周期协调？

写作依次回答四个问题：研究对象为何需要这三步；现有方法分别解决到哪一步；三项工作各新增什么机制与证据；它们怎样构成一条技术路线。先确定论证结构和每项工作的边界，再展开章节与页面；训练参数、代码任务和完整公式留到必要的说明位置。
