# 硕士模板与同组报告：格式对照及修改记录

检查日期：2026年10月9日。依据为本轮上传的同济大学学术学位硕士选题报告模板、张泽旭的正式Word报告及当前正式稿。检查重点是格式和填写规范，不比较两人的研究结论。

## 一 模板核对

本轮硕士模板代替此前的博士模板。硕士填写说明要求一般查阅不少于30篇文献，书面报告一般4000字以上；此前博士模板的相应数值为40篇、5000字。两份模板的必备内容、A4页面、页边距及三列研究进度表基本一致。现稿已有40条正文引用和16,157个正文汉字，不含参考文献，满足硕士模板的数量与篇幅要求。

硕士模板要求说明研究背景、国内外现状、研究问题与内容、研究方案及技术路线、技术难点、创新点、研究进度、基础与可行性和预期成果。现稿逐项覆盖。模板未要求将这些内容固定为与同组样例相同的章数，也未列出篇幅上限。

## 二 与张泽旭正式稿的主要差异

已提取张泽旭报告的全部章节与样式信息，并查看第1、2、14、18、19、22、29、31页，核对正文、章节转换、图题、参考文献和进度表。以下结论限于这些格式证据。

| 检查项 | 张泽旭正式稿 | 当前正式稿 | 处理意见 |
|---|---|---|---|
| 页面 | A4；上下2.5厘米、左右3.17厘米 | 相同 | 保留 |
| 开头 | 填写说明与报告内容从第一页衔接，先写研究问题 | 填写说明单独一页，正文从研究背景开始 | 模板没有规定同页开头；保留现稿顺序 |
| 章节组织 | 研究问题、文献综述、研究内容、研究方案与技术路线、可行性与研究基础、预期成果，最后列研究进度 | 背景、现状、问题与内容、方案路线与难点、创新点、基础与可行性、进度、成果、参考文献 | 必备项目均已覆盖；现稿创新点独立成章，不影响规范 |
| 字体与字号 | 默认正文样式为宋体10.5磅、英文Times New Roman；部分标题另设黑体 | 正文仿宋14磅，标题黑体，英文与数字Times New Roman | 属于排版差异；填写说明没有将默认字体规定为强制标准，本次保留现稿字体 |
| 段落 | 正文常用首行缩进两字符，部分段落使用1.5倍行距 | 首行缩进两字符，正文固定24磅行距 | 缩进一致；保持全稿行距统一 |
| 图表 | 图居中、图题置于下方；进度采用三列表 | 图居中、图题置于下方；表题置于上方；进度三列表 | 与样例的主要写法一致 |
| 参考文献 | 放在综述之后，共53条 | 全文末尾，共40条 | 位置与条数无需照搬；保留编号连续及正文对应 |
| 页码与篇幅 | 渲染共32页，末页为空白，主要内容31页 | 36页，含说明页，连续页码 | 模板没有规定页数；不将样例的空白页作为要求 |
| 课题来源 | 写出其对应的基金项目 | 说明工业工艺数据与已有研究基础 | 不移植他人的项目或资助信息；模板未单列强制的“课题来源”栏目 |

对照没有发现必须大幅重排的格式问题。本次调整限于硕士填写说明、图1及对应说明，已确认的章节论证与三项创新点保持。

## 三 图1替换

原图为Bao等论文中的图6截图。重绘保留原图的主要布局与信息关系：上层三个工序前序图，中层三架飞机及对应站位，下层人员团队。按用户要求删除工具资源一行和原英文图题，使用黑白中文标注。矢量文件不包含嵌入的原截图，文字、节点、飞机轮廓和箭头均为SVG对象。

新图以原生SVG嵌入Word，同时附PNG用于兼容显示。正式报告中编号仍为图1，图注为“飞机脉动装配线的工序、站位与人员关系示意，参考Bao等[6]重新绘制”。参考重绘仍须注明来源，不能因替换截图而删去原文献归属。

三个站位是生产组织示意，本文研究的五个串行站位设置未改变。正文只改图1引入句与图注，研究目标、方法方案、实验状态、创新点、计划和其余引用不作调整。

## 四 交付与检查

已检查修订后的全部36页，图、图题、表格、公式及页码显示完整，未发现新增文字重叠、裁切或缺图。参考文献40条全部有正文引用；五幅图和六张研究表的数量不变。原图截图不再嵌入新Word，独立SVG可编辑。

当前字体设置在Word中保留；预览PDF因环境字体不足使用替代字体。学院提交仍需填写学号姓名，按模板要求命名，并在本机Word中核对后导出PDF。
