# 基于图神经网络与强化学习的飞机脉动装配线调度方法研究

## 1.2.2 选题依据

（1）研究飞机脉动装配线调度的必要性

国产大飞机的规模化、系列化发展，对总装制造能力和生产组织提出了相应要求。《中华人民共和国国民经济和社会发展第十五个五年规划纲要》提出推进国产大飞机规模化系列化发展，并推动智能制造；《“人工智能+制造”专项行动实施意见》提出建设航空航天智能化制造体系，开展复杂构件加工与装配的人工智能应用。飞机总装涉及大部件对接、管路和线缆敷设、设备安装及系统检测等作业，合理安排工序和人员，是提高装配生产效率的重要环节。

飞机装配可以采用固定式、续动式和脉动式等生产组织方式。固定式装配中，飞机主体保持在固定位置；续动式装配中，飞机缓慢连续移动；脉动式装配采用驻站作业和同步转站，飞机在站位内进行装配，随后转入后续站位[1]。本课题依据调研工厂的五站位脉动装配线开展研究，飞机从一号站位进入，沿产线依次完成装配，不同站位可以同时装配不同飞机。图1示意了工序、飞机、站位与人员之间的关系。

在本课题模型中，相邻两次转站之间，飞机停留在本站进行装配。等各站飞机完成当前安排在本站的作业后，全线统一转站：五号站位的飞机离线，其余飞机各向前移动一个站位。若本批次还有待投产飞机，新飞机同时进入一号站位。各站的作业完成时间因而共同决定实际转站时刻，调度需要结合整线的生产进度安排本站作业。

（2）研究工序、站位与人员联合调度的必要性

飞机装配中的工序安排、站位分配和人员团队选择相互制约。工序选择需要满足工艺前序；站位分配改变各站的任务组成和可选人员；团队成员的资格、效率及占用影响工序能否执行和作业时长。人员首次被指派到某站位后，在当前阶段保持该站位绑定，其后续能够承担的作业也会受到限制。因此，一项工序的安排会同时改变后续工序和人员的可用条件。

工序分站与站内作业时间需要共同考虑。装配线平衡主要研究工序向有序站位的分配，在工艺前序等约束下优化站位数量、周期或负荷目标[2]；调度进一步确定执行顺序、起止时刻及资源使用。飞机总装已有将工序分站与资源约束下的任务调度联合求解的研究[3]。即使各站承担的工作量相近，前序关系和人员冲突仍可能使各站完成时间不同，仅比较工作量难以评价实际排程。

本课题的工序需求人数由工艺数据给定，人员安排需要选择满足资格和占用条件的具体成员。工艺前序、技能匹配和资源占用分别反映不同的生产关系，联合调度需要同时利用这些信息，避免某项选择过早限制后续可行安排。研究工序、站位与具体团队的联合选择，有助于在满足生产约束的条件下缩短排程完工时间。

（3）研究工序延迟开工下重调度的必要性

物料未就绪等原因可能导致工序延迟开工，使尚未开工工序的最早可开工时刻推迟。本课题关注延迟发生后的计划调整。扰动发生前，其时刻、目标和程度不可见；发生后获知本次持续时间或新的最早可开工时刻。已开工工序连续执行至完成，不因这类扰动中断。

工序延迟并不必然造成同等程度的整线延迟，其影响取决于工艺前序、人员占用及原排程中的时间余量。稳定基准排程和飞机装配重调度研究分别讨论了时间缓冲、剩余作业完成条件及计划改动等问题[4,5]。局部延迟可能被已有余量吸收，也可能推迟本站就绪，进而改变共同转站时刻。因此，延迟发生后的调整需要结合其他工序和人员安排，判断哪些作业受到影响、哪些安排仍可保留。

基准排程是生产安排及计划改动的参照。扰动发生时，部分工序和人员安排已经形成，重新安排全部作业可能增加现场调整负担。本课题需要保留规定工序的原安排及已形成的人员站位绑定，对允许调整的部分进行重调度，在修复后的完工时间与计划稳定性之间进行权衡。

（4）研究多架次飞机装配协同动态调度的必要性

多架次连续装配中，不同飞机处于不同站位，各自的工序进度通过同步转站相互联系。共同转站时刻由最晚就绪的在制站位决定；若一架飞机的局部延迟推迟了这一时刻，其他飞机的转站及下一架飞机的投产也会相应推迟。因此，单架飞机或单个站位的安排需要结合其他在制飞机的实际进度进行评价。

部分飞机装配线允许未在原定站位完成的作业随飞机转站后继续安排[6]。这种局部调整提供了后移作业的可能，也会改变后续站位的任务组成。本课题考虑的有限工序后移需满足工艺前序、单向流动和人员约束，且不迫使其他工序换站。当前周期中的决定因而可能同时影响本站等待和下一周期的作业条件。

多架次协同调度需要跟踪各架飞机的工序进度、站位任务和人员状态，并判断局部变化对共同脉动及后续作业的时间影响。将当前周期与紧邻下一周期的联系纳入决策，可以为不同飞机的作业协调提供更具体的生产信息。

本课题围绕上述生产需求，从无扰动条件下的联合静态调度出发，进一步研究不同生产关系的表示及延迟开工后的计划调整，再扩展到多架次连续装配中的协同动态调度，分别研究同构图、异构图和语义增强图网络方法。

## 3.1 研究对象

本课题以飞机脉动装配线的装配作业及人员安排为研究对象，依据调研工厂的五站位产线开展研究。同型号飞机依次通过各站位进行装配，不同站位可同时承担不同飞机的作业。各站飞机完成当前安排在本站的作业后同步转站，末站飞机离线；若还有待投产飞机，下一架同时进入一号站位。

工序执行受到工艺前序、需求人数、人员资格、占用及站位条件的约束。工序延迟开工可能改变本站就绪时刻，并通过共同转站影响其他飞机的进度。本课题研究上述生产过程中的工序安排、执行站位、具体人员团队及作业时间，以协调各站作业和多架次装配进度。

## 4.4 基于语义增强图网络的多架次飞机装配协同动态调度方法

建立多架次事件驱动仿真环境，按工序开工、完成、扰动发生和同步转站推进生产过程，分别记录各架飞机的位置、工序进度及已提交安排。以各在制站位的最晚就绪时刻确定实际转站时间，末站飞机完成全部工序后随共同转站离线。已提交的实际执行安排不能主动撤回或改派，已开工工序连续执行至完成。尚未提交安排的工序，仅允许在不迫使其他任务换站的条件下后移至紧邻下一站，合法范围通过动作掩码确定。

这些执行状态既包含各架飞机的局部进度，也包含各站的任务与人员条件。在完整工序图和资源关系编码的基础上，分别汇总工序与飞机、站位和整线信息，形成联合决策所需的状态表示。各站的下一周期信息对应下一次实际脉动后进入该站的飞机，只使用当时已知的任务及人员条件。各层生产状态按事件影响范围更新，每次完整决策前统一计算最新表示，并采用多层感知机融合。分层信息融合与更新见图3。

在融合后的状态表示上增加时间预测模块，以当前状态和最近变化为输入，预测在当前策略下继续执行时，本次共同脉动相对现有估计的时间修正，以及紧邻下一周期各站相对参照时刻的就绪偏差。偏差表示提前或延后，这些预测量具有明确的生产时间含义，作为图表示的补充信息，供联合策略选择工序、站位和团队。当前预测还用于奖励塑形，下一周期预测用于提供后续作业的时间信息。

预测所需的监督标签由后续实际脉动和站位就绪记录形成，不提前读取尚未发生的扰动；无飞机或不存在下一周期的目标使用有效性掩码排除。联合策略采用PPO训练，图编码与分层融合同时接受调度回报和时间预测监督。采样与策略更新保持预测特征版本一致，网络参数按训练批次更新。通过对照与消融，分别检验分层融合、预测监督、预测输入、奖励塑形及下一周期信息的作用。

## 4.5 实验验证方案

### 4.5.1 数据基础

采用四种规模的实际工厂装配工艺数据，工艺前序、标准工时及需求人数来自原始数据；人员总量、资格和效率按实验方案设置。各方法使用相同工艺与人员条件开展仿真验证，并沿用数据明确规定的站位条件。

### 4.5.2 对照与评价

研究内容一在无扰动场景下，与规则、搜索及图强化学习方法比较排程完工时间和计算开销；研究内容二在工序延迟开工场景下，比较重调度后的完工时间、相对基准排程的改动及修复耗时；研究内容三连续执行指定批次，与固定站位、有限后移等对照比较整批工期、周期超期和计划改动，检验分层信息、时间预测及相邻周期信息的作用。
