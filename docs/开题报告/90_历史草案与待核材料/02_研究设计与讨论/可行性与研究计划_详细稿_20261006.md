## 1. 研究基础

### 1.1 生产问题与数据基础

本课题已明确飞机脉动装配线的生产对象、决策内容及主要约束，围绕工序排序、站位分配和具体人员团队选择建立联合调度问题。给定站位沿工艺流向排列，任务执行受完整前序、人员资格和占用约束，各站实际就绪共同决定同步脉动。上述边界已与数据说明及方法确认稿对齐，为后续方法构造和仿真验证提供明确依据。

研究已具备283、680、2338和3182四种规模的工业工艺数据及配套README，可支持不同工艺规模下的建模与验证。工艺前序、标准工时和需求人数来自工厂，人员总量、资格与效率采用设定配置。已有数据足以支撑当前研究问题，不需要以额外构造物料映射、设备、疲劳或空间容量来完成首版验证。

同型号飞机采用相同工艺模板，可在实际事件驱动环境中展开为不同飞机—工序实例，并分别记录位置、进度和开工限制。虚拟节点与物理任务的统计边界、初始参考排程与当前有效安排的区别已经明确，能够为完整依赖处理、轨迹核查和实验复现提供基础。

### 1.2 方法和论文基础

前期已开展飞机装配联合调度研究，形成CAC 2026已录用论文，涉及图表示、工序—站位—团队联合选择、可行时间分配和强化学习训练。该论文为后续研究提供方法与实现基础。开题中的研究内容一按用户确认方向，将原模型的图编码作最小同构替换，其他机制尽量保持一致；新的同构版本仍需对应实施与验证，原异构模型结果不直接作为其效果。

研究内容二已有当前未投稿论文稿，包含异构联合调度和工序延迟开工后的重调度。稿件已报告初始调度、结构比较、固定延迟场景、效率与稳定性分量、配对统计及求解耗时，可用于说明本课题具有受扰调度研究基础。其结果按原论文任务和测试范围解释，不扩大为全部扰动类型或新多架次执行环境中的效果。

研究内容三已完成首版方法及实验设计的阶段讨论，明确事件驱动执行、工序／飞机—站位—整线分层融合、当前及紧邻下一周期语义、有限合法后移、预测副本与标签回填等接口。已有部分代码为开发基础，但代码尚未完成，当前没有完整方案性能证据。因此，研究三的可行性依据是明确的设计、可复用的共同机制和分阶段验证安排，而非已经取得的生产收益。

### 1.3 文献与论证基础

已形成生产背景、三节文献综述、研究目标、三项研究内容、拟创新点及总体技术路线等详细资料，并归档主要参考文献及关键论点来源。研究组织遵循导师要求，由同构图静态调度发展到异构图动态调度，再进入语义增强的多架次协同动态调度。

各阶段的增量已有明确问题对应：工作一研究工艺与资源耦合下的联合安排，工作二加强不同关系的信息利用并处理延迟后的效率与计划稳定性，工作三研究实际同步脉动下的时间后果与多架次协调。这些资料为开题论证和后续论文写作提供基础，也使新增实验可以围绕具体问题安排，避免将多个算法并列堆砌为研究内容。

## 2. 可行性分析

### 2.1 模型与方法的可行性

三项研究采用共同的工艺和人员条件，通过图编码提供信息、联合策略选择动作、合法性检查与时间分配落实可行安排。状态表示与硬约束分工明确，因此改变图类型或引入语义模块时，可以保留对应的生产规则，分别核查表示变化和决策变化的影响。

工作一采用原模型的局部编码替换，所需新增工作主要在统一特征接口、共享消息传播和原读出适配，无需从零重建联合调度框架。工作二具有当前论文方法和已有实验基础，其后续任务主要为结果整理、稿件修订及有必要时的受控补强。工作三复用已有图与联合动作骨架，将新增工作分解为实际执行环境、分层读出、时间预测、标签结算和训练组织等模块。

工作三时间标签可由实际执行日志获得：共同脉动和各站首次就绪均具有明确事件定义。采用历史状态保存、分项标签回填和有效性掩码后，可以在结果出现时形成对应监督，不要求获取未来未知扰动。当前周期和紧邻下一周期构成首版有限预测范围，有助于控制开发与验证规模；动作条件预测和其他复杂扩展暂不进入首版。

上述设计使研究能够分步实施，并通过可审计轨迹发现模型与接口问题。方法能否改善排程质量仍由正式比较回答，不以结构合理或模块可实现替代性能证据。

### 2.2 实现与验证的可行性

已有论文和代码提供数据处理、资源约束、图表示、联合解码及强化学习训练等基础。新同构实现与工作三开发分别围绕已确认接口推进，必要兼容性通过小案例核对。工作三尤其需要确认完整虚拟依赖、正式决定不可撤回、实际同步脉动、单工序无连带迁移后移以及账本与标签的一致性。

验证按“物理过程—真实费用及标签—信息边界与预测—PPO链路—正式比较”展开。先在可人工复核的小实例上取得完整合法轨迹，再扩大训练与测试，能够避免将大量算力消耗在错误的生产过程或标签上。工作一新同构和工作三实际环境的部分准备可交错推进，但正式训练以对应接口与物理规则核查通过为前提。

研究方案已区分主比较、必要消融和后续扩展。优先获得能够回答核心问题的生产指标及机制证据，再根据结果安排跨规模、批量或更复杂扰动验证。工作二未报告的补充实验按学位论文需要决定，本次开题材料不依赖立即新增实验。

### 2.3 计算与组织条件

拟租用AutoDL服务器，以RTX 4090 GPU承担模型训练及批量测试；小案例检查和文稿整理可在本地完成。用户已说明算力问题不大，因此本课题可以按服务器训练安排推进。实际服务器配置、可用运行时长和各模型显存占用在实施时记录，不以原论文硬件代替当前实验条件。

正式实验前，先测量不同工艺规模下的单条生产轨迹、模型前向、小训练及标签记录开销，再确定训练规模、批次飞机数、独立种子数和测试场景数量。尤其将工作三完整预测副本的计算与存储计入成本，避免只根据在线网络参数量估计整体开销。GPU条件为实施提供资源基础，不预先保证最大规模和全部实验可在某个固定时长内完成。

近期优先完成开题详细稿、章节整合和展示材料，本周加快推进，并结合导师反馈准备预计10月下旬的正式开题。实验开发与论文修订按阶段交付物组织，不将尚未完成的工作三正式训练设为开题材料收束的前置条件。

## 3. 主要难点及处理安排

| 主要难点 | 可能影响 | 处理安排与验收依据 |
|---|---|---|
| 同构替换的输入与读出兼容 | 编码改变可能误改原联合动作或丢失资源信息 | 仅进行必要接口适配，检查保留的信息、原约束、完整动作和可行轨迹；新版本单独训练 |
| 实际多架次轨迹与完整前序一致 | 虚拟依赖丢失、非法后移或误判完成会使后续结果失效 | 小案例验证完整DAG、单向流动、人员占用及正式决定；独立日志确认全部物理任务实际完成 |
| 延迟标签及预测特征版本管理 | 标签错周期、伪零目标或重放输入变化会影响辅助学习与PPO | 保存不可变历史状态，分项回填，跨采样段保留；完整轨迹内固定预测副本，重放使用当时值 |
| 预测误差改善但生产效果有限 | 时间信息可能未被动作有效利用，或仅在部分场景有收益 | 分开检查预测、输入、塑形、分层与下一周期对照，报告真实分项和适用条件 |
| 计算成本与试验数量增加 | 扩展实验可能挤占核心验证及写作时间 | 先测成本，优先主比较与必要消融；扩展根据结果和预算安排 |

以上处理沿现有设计，不借问题处理新增一套网络或放宽生产约束。若某一机制收益有限，优先核查数据、实现和对照，再据实说明适用范围；不通过挑选测试事件或隐藏失败实例改变结论。

## 5. 预期成果

拟形成面向飞机脉动装配线的图表示学习与强化学习调度方法体系，覆盖无扰动条件下的同构图联合调度、工序延迟开工下的异构图联合调度与重调度，以及多架次实际执行中的语义增强协同动态调度。三项研究共同回应工艺与资源耦合、扰动后效率与计划稳定性、同步脉动及跨周期协调等问题。

拟完成相应模型与仿真实现，形成数据配置、实验协议、完整执行日志、主比较及必要消融等可复核材料。通过生产指标、约束检查、机制对照和计算成本分析，明确方法的实际表现、适用条件和局限，并据此完成硕士学位论文。
