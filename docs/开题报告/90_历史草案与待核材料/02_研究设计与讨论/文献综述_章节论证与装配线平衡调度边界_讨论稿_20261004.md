## 2. 先处理2.1：平衡与调度怎样接起来

原始研究中，装配线平衡的基本内容包括将任务分配到一系列站位、满足前序约束；SALBP-2在给定站位数量下最小化周期时间。[S1] 本轮仅以作者摘要核对这一基础定义，不把SALBP假设全套照搬到飞机脉动线。

按本课题的决策内容解释：

| 决策 | 直观含义 | 本研究怎样处理 |
|---|---|---|
| 工序向站位分配 | 哪些工序在哪个站位完成？ | 策略选择可行站位，满足前序站位顺序等既有约束 |
| 工序安排次序 | 当前优先安排哪些可行工序？ | 自回归策略选择工序；构造顺序不等于真实开工顺序，也不改工艺拓扑 |
| 人员分配 | 由哪些符合条件的人员完成？ | 给定所需人数，选择具体团队；已有绑定规则按模型保留 |
| 开工与完成时间 | 在前序、释放和资源条件允许时何时开工、何时完成？ | 由已有可行时间分配机制确定，不虚构额外的直接时间动作 |

这里按决策内容区分概念，不把平衡绝对等同长期设计、调度绝对等同短期执行；也不说扩展平衡研究一概不含人员或排序。本研究从平衡相关的跨站任务分配引入，直接研究的是工序、站位与人员联合调度。工序具体安排影响本站就绪，最晚站位又影响同步脉动，因此仅凭各站名义工作量不能替代完整调度评价。

本研究的站位数量与已有资源条件给定，不把站位分配说成重新设计站位数；人员分配是具体团队选择，不把它扩大为招聘、总编制或任意跨站人员调整。“多资源”在正文须列明当前模型实际资源及约束，不能增加数据集不存在的设备或空间条件。

## 3. 2.1建议分成四个论证段

1. **从平衡问题建立概念。** 解释任务、站位、前序和周期时间，说明平衡与排序、资源安排可能共同影响生产表现。引文采用明确定义的原始研究或综述，不做过长分类目录。
2. **落到APAL的联合决策。** 说明同步脉动下的工序排序、站位分配和具体人员团队；分析研究中哪些决策被同时优化、哪些资源规则被保留。人员是三项研究的共同因素，不单独作为工作二出现的理由。
3. **加入扰动后的调整。** 说明工序延迟开工改变可执行条件，原有安排可能需要修订，评价同时包含完工表现与计划偏离。原因不在本段锁死为物料，已有实验覆盖范围按原论文注明。
4. **扩展到多架次实际连续运行。** 解释同一时刻不同站位上的在制飞机，以及最晚站位决定同步转站；局部延迟影响其他飞机与后续周期。固定模板稳态展开与受扰切换时在制品实际执行区别说明。

结尾需提出研究需求，但“较少文献考虑多架次”“现有方法只考虑单机”等判断须先核对具体模型和样本；当前不写成整个领域的确定结论。

## 4. 2.1末段衔接草案

飞机脉动装配线中的工序向站位分配，需要与工序安排次序及具体人员分配共同考虑。工序延迟开工后，还需在既有执行约束下调整计划，并兼顾完工表现与计划稳定性。进一步面向多架次实际连续生产，各站飞机进度共同决定同步脉动，局部延迟可能影响其他飞机及后续周期。因此，本课题依次研究无扰动联合调度、扰动下动态调度与多架次协同动态调度。

这是概念与研究范围的过渡底稿，不替代逐篇文献分析；正式综述在此段之前应提供具体文献的对象、决策、扰动与执行范围对照。图方法在2.2与2.3继续论证，不为凑齐网络名称在2.1过早作性能结论。

## 5. 2.2应比较什么

每类方法按相同维度分析：如何选择工序／站位／团队；如何处理可行性；一次求解时间与重复求解成本；扰动响应方式；是否需要重新训练；规模与场景变化的适用边界。数学优化可以作为小段补充，不改变导师要求规则、元启发式与强化学习的主比较顺序。

不能先写“规则不适应动态”“元启发式必然过慢”“强化学习不需要计算”再寻找引文。规则与搜索方法可用于动态调度，RL也有训练和推理代价；比较应限定到具体任务、规模、计算预算和评价。学习式联合决策的必要性以相应证据说明，不以方法新旧划线。

2.2结尾拟回答：针对APAL联合动作与约束，学习式策略可以研究怎样利用状态关系生成可行安排，但图信息组织、动态状态与作用路径仍须具体设计和验证。强化学习在其他调度领域的进展只能提供潜力和方法依据，不能直接保证APAL效果。

## 6. 2.3应怎样引出异构和语义

两条需求分别论证：

- 工艺前序、技能匹配与资源安排具有不同意义，需要分析显式节点／关系类型及针对性传播是否有助于联合调度；同构表示已有的属性信息不能忽略。
- 在制多架次状态影响共同转站及下一周期安排，需要分析当前事实编码与可监督时间后果之间的区别，以及辅助时间预测怎样进入策略；复杂系统中出现多架飞机本身不自动证明必须采用某个语义网络。

具体缺口限定为本研究已明确的执行与评价范围。工作三的“情景理解”沿已确认的事件与后果语义，指理解现场状态对当前转站及紧邻下一周期的时间影响；不默认新增知识图谱、LLM、人工情景分类、独立多智能体通信或未发生扰动的提前预知。

同构图可以用于动态任务，异构图也可以用于静态任务，二者在本课题中的先后是研究组织而非技术限制。图信息差异和效果差异分开；相关对照必须按相同任务与约束解释。
