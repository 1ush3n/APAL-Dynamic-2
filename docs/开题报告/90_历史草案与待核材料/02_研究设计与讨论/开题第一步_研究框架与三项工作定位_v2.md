## 1. 总体定位与已确认条件

**确认总题目：基于图表示学习与强化学习的飞机脉动装配线调度方法研究。**

### 1.1 确认的中英文名称

| 工作一 | 基于异构图与自回归决策的多资源联合调度 | Joint Multi-Resource Scheduling via Heterogeneous Graphs and Autoregressive Decision-Making |

### 1.2 总体研究主线与共同边界

本课题围绕飞机脉动装配线的工序排序、站位分配与人员分配，按照“无扰动静态调度—扰动下动态调度—多架次协同动态调度”逐步展开，并相应研究同构图、异构图及语义增强图网络的状态表示方法。

工作一首先面向无扰动条件下的静态调度问题，采用同构图统一组织工艺与资源信息，通过自回归策略联合进行工序排序、站位分配和人员分配，构造可行排程。在此基础上，对工艺前序、技能匹配和资源安排等不同关系的针对性处理仍需加强，且无扰动条件下的研究尚未覆盖工序延迟开工后的计划调整。因此，工作二引入异构图，分别组织不同实体及关系的信息，并研究工序延迟开工扰动下兼顾完工时间与计划稳定性的动态调度。

### 2.1 工作一的研究定位

面向无外部扰动条件下的飞机脉动装配线，研究同构图表示支持的工序、站位和具体工人团队联合决策，通过自回归策略与可行性约束生成基准计划。按10月6日确认方向保留原工作一模型的工序、站位、人员信息及联合动作、约束、时间分配和训练组织，仅将图编码改为单一图上的共享传播并完成必要接口适配；具体算子待实施核对。工作二论文中的Homogeneous GraphSAGE变体仅作原设置参考，不作为新同构方案的默认实现或结果。约束以实际数据、采用模型与环境配置为准。CAC原论文的三实体异构图属于既有基础，不改写其方法事实。

本项重点是多资源联合建模与基准计划生成。自回归决策指后续选择以已经作出的选择为条件，不因多个动作阶段就称为“分层强化学习”。人员选择是联合动作的一部分；第二项进一步研究扰动与承诺继承条件下的人员调整，不需要从第一项中删除人员因素来制造两项工作的区别。

### 2.2 工作二的研究定位与标题核验

**工作介绍（不改既定标题）：** 研究基于异构图的联合调度与考虑计划稳定性的重调度。首先区分工序、站位、人员和技能及其关系，为联合决策提供状态表示；工序延迟开工后，将基准安排、已揭示的开工条件变化与冻结状态纳入修复状态，继承冻结条目和人员站位绑定，调整允许修改的工序、站位与具体团队。现有物料就绪延迟实验仍按原论文范围解释。

#### （1）为什么能够称为“人员分配优化”

本轮当前核验依据为用户新提供的工作二未投稿稿《工作二_拟投IEEE_TSMC_Systems_联合调度与人员分配_未投稿稿_20261003.pdf》，题名为 *Joint Scheduling and Workforce Allocation for Aircraft Pulsating Assembly Lines via Heterogeneous Graph Reinforcement Learning*。判断依据来自实际模型与决策机制，而非仅凭论文标题。

| 核验维度 | 论文中的直接依据 | 对标题的支持 |
|---|---|---|
| 人员是否属于决策变量 | 第III节表I定义人员分配变量y_iw和具体团队W_i；第IV-A节联合动作包含工序、站位和团队 | 模型决定具体由谁执行任务，属于人员分配 |
| 人员选择是否影响生产结果 | 第III-B节式(1)中，作业时长D_i(W_i)取决于被选工人的效率 | 人员选择会改变加工时长及后续资源占用，具有优化意义 |
| 是否满足人员适配约束 | 第III-B节式(5)—(7)约束团队人数、技能、站位专属和工人时间互斥 | 人员分配在明确的物理可行域内进行 |
| 扰动后是否仍有人员决策空间 | 第III-D节冻结集合继承原团队；可调整工序保留团队选择空间；既有站位绑定继承，仅原先未使用工人仍可未绑定 | 属于承诺约束下的人员重新分配，不是任意跨站调动 |
| 是否权衡人员调整代价 | 第III-D节式(13)纳入团队变更率R_team，系数为0.3，同时考虑完工与其他计划偏离 | 人员安排既影响效率，也进入稳定性评价 |

**核验结论：可以采用“人员分配优化”。** 工人团队是算法的决策变量，其选择影响时长、资源可用性和稳定性目标；无需另设一个独立的“人员目标函数”，也能构成联合调度中的人员分配优化。“优化”不表示已证明全局最优，也不表示每个扰动场景均优于所有对照。

每道工序的团队人数q_i是给定参数，优化的是具体成员及其可行分配。现有工作不据此主张优化企业总用工人数、岗位编制、招聘培训或任意跨站调配。“人员配置”可以有宽泛的资源配置含义，但若不作限定容易扩大研究范围，故正式名称统一采用用户选中的“人员分配优化”。

#### （2）为什么能够称为“预测—反应式调度”

经典重调度框架将预测—反应式调度概括为先形成生产计划，再根据扰动或事件更新计划；一次扰动后的计划修订也可属于这一框架。[Vieira、Herrmann与Lin，第5.2节](https://isr.umd.edu/Labs/CIM/projects/jos-rescheduling.pdf)

本研究对应过程为：先生成基准周期模板，在物料延迟信息揭示后，以冻结边界和既有绑定限制调整范围，再修复后续可调整计划。“预测”在此指预先制定计划，不要求新增物料预测网络。当前更新后的物料释放时间在重调度触发时已知，不应改写为已具备到料时间预测能力。

工作二在自身异构联合调度基础上开展受扰修复，自回归动作、通用约束及时间分配属于共同方法基础。两项研究的衔接由关系区分与扰动响应需求引出；基准排程是重调度的生产背景、保留条目依据及偏离参照，不作为工作一向工作二传递成果的创新论证。

#### （3）与标题匹配的研究内容与证据边界

1. **预测计划与图状态表示：** 形成可供扰动响应使用的基准计划，显式表达工序、站位、工人和技能关系，并引入基准安排及扰动信息。
2. **反应阶段的联合决策：** 固定冻结任务，继承所有基准已使用工人的站位绑定，为可调整任务选择工序顺序、可行站位与合格团队。未开工不等于所有相关人员都可跨站重新绑定。
3. **恢复效率与计划稳定性的权衡：** 同时评价完工表现、相对基准超限、开工偏离、站位变化和团队变化，避免只追求局部时长缩短而引入大量计划变更。
4. **人员分配效用的验证：** 在已有模型中，人员分配属于优化变量已得到确认；若要进一步声称“人员分配机制带来独立增益”，应使用对应消融或受控对照。建议在同一扰动、冻结边界和绑定规则下，对比允许团队调整与保留原团队的方案；后者若不可行，应独立报告可行性，不能将未完成方案当作低完工时间结果。

上述对照属于建议补强，不能写成已完成实验；判断标题成立并不以增加新实验为前提。团队变更率低也不必然代表方案整体更优，应结合效率与可行性共同解释。

### 2.3 工作三的研究定位及与工作二的区别

**定位表述：** 面向多架飞机连续装配过程中扰动影响的跨架次传播，研究基于状态表征学习的动态协同调度。复用完整异构图，按工序／飞机、站位当前／下一周期及整线生成MLP融合摘要；以实际当前转站残差和紧邻下一周期各站有符号就绪偏差监督共享表示。网络方案B以轨迹固定完整副本提供预测数值，在线Actor与辅助头继续训练，支撑不可撤回决定下的留站／无连带迁移后移选择。

本课题中“多架次协同调度”的操作性含义是：统筹同一产线上不同在制飞机的任务及跨周期衔接，在调整当前任务时考虑其他飞机和未来周期的影响。协同关系必须进入模型、决策范围和整体评价；仅重复一份固定模板不足以验证此项贡献。

工作二重点是计划层面的周期模板修复；工作三处理飞机身份、实际执行与跨周期影响。同步脉动使各站飞机进度共同决定转站时刻，局部延迟可能影响其他飞机与后续周期，因此需要理解事件的分层时间后果，支持任务统筹。新增辅助目标监督当前残差和下一周期站位时间结果，区别于综合价值回归。首版以具有时间单位的输出解释预测结果；人工情境类别、聚类、双模拟保证和原因解释均不作为必需组件。

## 3. 第三项的核心研究假设与范围

**研究假设：** 对同型号飞机的连续脉动生产，若潜在状态表示保留了调度行为对即时损失、资源后续可用性和跨周期运行的影响，则可能改善滚动协同策略的决策质量与跨情境适应能力。该假设必须通过同一多架次环境中的受控比较检验。

情境不要求预先人工分类、命名或赋予人类语义。首先学习以实际转站时间为监督的连续任务相关表示，原型等保留扩展。实际执行结果产生训练信号，因此更准确的表述是“无需人工情境标签的表征学习”，而非完全没有监督信号。

主路线已选为当前周期时间残差与下一周期各站有符号就绪时间偏差预测；预测准确性、动作输入收益、跨周期模块与既有塑形收益需要分别检验。本阶段完成方法定义，尚不展开新的实验矩阵；旧有聚类、原型比较保留为后续可选验证。

工作三当前边界（如需改变，应明确说明新增假设）：

1. 同型号、共享工艺模板，但每架飞机有独立的任务完成状态、工序开工可用性和实际站位；工人是产线共享的物理资源，不能随飞机复制。
2. 同步脉动、飞机单站占用、完整DAG前序、数据限定站位、技能／人数及工人互斥为硬约束。已有明确环境上限注明为配置，不引入未使用部位容量对应的空间限制。已开工非抢占，已提交决定不可主动更改，正式后移另计成本。
3. 后移决定在飞机当前站位作出，每次只改变所选未决工序的有效目标站位至紧邻下一站，并满足无连带迁移条件；加工须等飞机实际到达目标站且满足前序与资源条件。飞机不能逆向返回或跨站并行。研究批次工人站位固定，未决任务可以选队，提交后的团队不可重选。
4. 先研究工序延迟开工（开工可用性延迟）：事件触发时揭示受影响飞机、未开工工序及新的开工下界R；触发前策略不能读取R。对命中工序更新r_new=max(r_old,R)，实际开工还受前驱、人员及站位约束。当前数据没有工序—物料映射，物料或工装只能作为潜在工程解释，后续可研究揭示误差。
5. 其他扰动作为扩展测试。工人缺勤影响共享资源供给，工时变化影响占用区间，执行中故障可能涉及中断；不能仅因均造成延迟就视为同一种释放时间变化。
6. 已揭示的开工可用时刻到达后，也不保证累计延迟归零。分别评估继续传播是否受抑制、剩余延迟大小，以及有可压缩周期/资源余量时能否追赶基准；不保证所有情境都能恢复原始绝对时刻。
7. 原始模板不改写，但时间稳定性比较相对于各自周期起点的开工位置，允许周期整体平移；实际节拍超过固定基准的部分独立计费。基准偏离与累计合法后移仍分别计量；旧版相邻安排时间／团队修订费用须按不可撤回规则重新核对，不再假设存在反复改队或重新预约。
8. 首版固定一组主要权重并报告各原始指标，辅以权重敏感性分析。若未来要求单一模型适应多组权重，应显式条件化偏好或保留分量代价信息，避免加权和抵消造成不合理聚合。

## 4. 方法借鉴与尚待核验的增量

Zhang等的DBC研究使用奖励差异与后继分布差异学习面向控制的表示，并区分严格动作条件下的双模拟定义与用于学习的策略相关近似。它提供方法启发，不自动赋予本课题最优性或策略保持保证。[论文全文](https://arxiv.org/html/2006.10742v2)
