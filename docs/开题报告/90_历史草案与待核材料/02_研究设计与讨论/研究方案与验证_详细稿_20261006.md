## 1. 总体研究方案

本课题围绕飞机脉动装配线中的工序排序、站位分配与人员分配开展研究。工艺前序决定任务执行条件，具体团队影响加工时间与人员占用，有序站位和共同脉动将不同任务及在制飞机的安排联系起来。研究以工业工艺数据为基础，通过图表示组织工艺与资源状态，以强化学习进行联合选择，并通过合法性检查和时间分配落实可行安排。

研究按照“无扰动联合安排—延迟开工下计划调整—多架次实际执行协调”逐步展开。研究内容一采用同构图统一编码，构造无扰动条件下的可行排程；研究内容二采用异构图区分不同实体与关系，同时研究扰动发生后的效率与计划稳定性权衡；研究内容三进一步跟踪在制飞机的实际位置和进度，融合工序／飞机、站位及整线信息，利用当前状态对共同脉动与紧邻下一周期的时间后果支持协同决策。

三项研究的衔接由前一项的研究边界及下一项需要增加的能力决定。工作一的排程输出可以作为生产计划，但“为工作二提供排程”不作为研究递进的依据。工作二已有周期模板也不等同于工作三的实际连续执行轨迹。对应验证分别评价静态排程、受扰修复计划和整批实际生产，避免将不同时间尺度的指标直接比较。

## 2. 数据、生产规则与实验场景

### 2.1 数据来源和统计范围

采用283、680、2338和3182四种规模的工业工艺数据。工艺前序、标准工时、需求人数等核心参数来自工厂；人员总量、资格与效率采用设定配置。因此，实验总体表述为“基于真实工业工艺数据，结合设定的人员资源配置开展仿真验证”。人员配置和事件生成参数在实验记录中单独列出。

数据读取及处理遵循归档README。完整工艺依赖包含物理任务和虚拟层级节点。虚拟节点可以在图中显式保留，或通过等价前序投影处理，其连接所表达的依赖必须完整保留；工作量、人数及物理任务数统计排除虚拟节点。物理任务按节点类型识别，不能因为工时为零而直接删除。没有显式前序的物理任务按现有规则具备初始前序就绪条件，其实际开工仍受人员及其他已有条件约束。

工艺模板规模、飞机数量、展开后的飞机—工序实例数和独立实验场景数分别统计。工艺随机变体需记录所改变的字段及其与原始工业图的关系，不能将所有变体参数都称为工业实测，也不能仅凭变体数量声称已经验证未见工厂或未见拓扑的泛化能力。

### 2.2 共同生产约束

各项研究均遵守对应模型中的工艺前序、站位单向流动、团队人数、人员资格、人员占用和站位绑定规则。除数据及已明确规则规定的开头少量工序外，不增加普遍的强制工序站位。硬约束由环境实际状态、候选掩码和时间分配落实；图表示为策略提供决策信息，不代替可行性检查。

工作二和工作三的调整范围分别按照各自模型定义。工作二在原论文的冻结和修复边界内调整可修改条目，阶段内继承已使用人员的站位绑定。工作三采用一个实际事件驱动执行环境：完整执行决定提交后，已选站位、团队及对齐方式不可主动撤回或修改，包括已经预约但尚未开工的决定；扰动只能使既定安排依据真实开工条件被动顺延。已开工任务非抢占执行，已完成任务不重排。

工作三首版采用五站同步脉动。同一飞机在一个实际周期内只位于一个站位，不能跨站同时加工。本站完成当前有效物理任务并满足已有约束后记录首次就绪，随后等待共同脉动，不设计就绪反复变化。实际脉动由所有有效站位中最晚的实际就绪时刻决定；存在待投产飞机时，在该实际脉动时刻补入一号站位。名义节拍不作为强制转站时刻。

### 2.3 三项研究的场景安排

| 研究内容 | 场景与时间范围 | 扰动信息边界 | 验证状态 |
|---|---|---|---|
| 一 | 无外部扰动的静态联合排程构造 | 沿原模型的已知工艺与人员配置 | 原方法已有基础；新同构设置拟验证 |
| 二 | 工序延迟开工后的计划修复 | 沿论文使用已揭示的释放变化和修复边界；现有实证为物料就绪延迟 | 初始调度与重调度已有论文实验 |
| 三 | 指定批次从空线开始到全部飞机实际完成 | 未发生事件的时刻、目标和程度不可见；发生后揭示恢复时刻 | 首版设计已确认，代码未完成，效果拟验证 |

工作三直接建模工序开工可用性延迟，不依赖当前数据中不存在的工序—物料映射。事件揭示后提高命中且尚未实际开工任务的最早开工下界；实际开工还须满足前序、飞机位置及团队条件。已开工或完成的任务不受此次开工限制影响；实际开工与扰动严格同刻时，先处理开工，该刚开工任务继续执行。

主实验沿既有确认稿，安排单次事件直接影响一架飞机当前站位的部分未开工任务。其他站位与飞机受到的影响通过同步脉动、资源占用及合法后移自然产生。早、中、晚为参考周期内的发生阶段，低、中、高为影响范围与持续时间共同定义的综合强度，组合形成九类场景，并覆盖五个直接受扰站位。这是九类场景组合，不是九种不同物理故障机制。

主要扰动安排在满线并完成一个正常周期之后，随后运行至整批实际完成，使评价能够包含影响传播及排空。各方法复用同一预先冻结的事件清单，运行时依据真实开工状态判定命中，不为某个方法重新挑选受扰任务。共同日历事件与不同算法实际进度的对齐方式，以及是否采用统一预热前缀，仍需在正式实验前核定。

批次飞机数、阶段具体时刻、持续时间分布、比例取整和最终强度量级沿原确认稿保留为待校准参数。先利用小案例与成本测量确定这些参数，再冻结正式协议；不因测试排名重新选择场景。

## 3. 分项研究方案与验证

### 3.1 研究内容一：同构图联合静态调度

以工作一原论文模型为基础，保留原有工序、站位和工人信息，以及联合解码、合法性约束、时间分配、人员绑定、奖励和PPO训练组织。将图编码改为单一图上的共享传播，并完成必要的特征与索引接口适配。优先在原注意力机制基础上进行最小替换，具体算子由后续实现核对确定。本轮不同时改换整套决策机制或增加新的生产变量。

同构表示为工序—站位—具体团队的条件选择提供共同上下文。策略逐步构造完整动作，随后由时间分配确定合法起止安排，更新资源占用和人员绑定，直至形成完整排程。验证首先检查物理任务完整性、前序、团队资格、人员互斥、站位流向和绑定；满足可行性后，再比较排程质量及推理成本。

性能比较按规则方法、搜索方法和图强化学习方法组织，参考原论文中的已有对照；实际复现范围与预算在新实验协议中明确。各方法使用相同工艺、人员条件、硬约束和静态评价定义。学习方法分别报告训练成本和测试推理成本，不能只比较训练曲线。

新同构版本需要单独实施、训练和测试。CAC原稿采用异构模型，其既有数字用于说明研究基础；工作二的同构GraphSAGE变体也是原论文特定设置，不能直接视为本次新同构版本的结果。后续若要更严格检验图类型的作用，应在同一任务中尽量匹配聚合算子、可见信息、动作、预算和容量，并明确输入适配与参数量的差异。

### 3.2 研究内容二：异构图联合调度与考虑计划稳定性的重调度

本项研究包含两个相互衔接的部分。初始联合调度按照当前论文构建工序、站位、人员和技能异构图，通过类型相关的信息传播为联合策略提供状态表示。重调度根据已揭示的开工条件变化，在原论文规定的冻结条目与人员站位绑定边界内调整允许修改的安排。

已有计划为冻结与绑定继承提供依据，为网络提供论文规定的基准条件，并作为计划偏离的固定参照。修复策略读取基准、已揭示延迟及当前修复状态，选择允许调整的工序、站位与具体团队，由前向时间分配落实合法安排。研究同时评价修复后的计划时间跨度和对原计划的偏离，使效率与稳定性的权衡得到明确呈现。

本次开题以已有论文实验为基础整理验证。初始调度及结构比较采用论文相应表格；受扰比较采用四个工业测试实例上的36个固定延迟场景，结合综合目标、开工／站位／团队分量、配对统计和修复耗时解释结果。原论文不同阶段和不同方法预算依其协议说明，不与CAC不同设置下的绝对排程数字直接拼接比较。

现有同构／异构结构比较还包含聚合算子等差异，其结果支持所测整体设置的比较，不能把全部收益归因于关系类型。当前综合分数对最近两项基线的Holm校正检验未达到显著性，报告时区分均值表现和统计结论；各稳定性分量也分别解释。耗时按原硬件和测量范围使用，不据此直接保证新环境实时运行。

相同聚合算子的图类型对照、特定关系通道消融及基准条件与偏离目标的拆分，可作为学位论文阶段的补充候选。当前论文未报告的实验统一视为未开展，本次写作不要求为开题立即补做全部候选。

### 3.3 研究内容三：语义增强的多架次协同动态调度

在实际连续执行环境中，保留完整可见工序图及资源关系，按未完成物理任务与周期角色生成飞机和站位摘要，再融合整线状态。飞机摘要反映任务进度与后续工艺，站位摘要分别组织当前任务集和紧邻下一周期任务集，整线摘要反映各站状态、实际周期位置及在制和待投产数量。首版采用MLP融合，每次完整决策前依据最新一致状态重算动态表示；生产事实刷新、神经表示重算与训练参数更新分别处理。

语义模块以当前状态和最近变化为输入，输出本次共同脉动的时间修正，以及紧邻下一周期各有效站位就绪时间的有符号偏差。预测跟随当前策略实际执行结果学习，首版不针对每个候选动作分别进行后果预测。实际事件形成监督标签，历史输入保存后按当前与下一周期结果分项回填；尚未结算的结果等待回填，无飞机的站位和不存在的下一周期采用有效性掩码。有飞机但当前没有待做任务不自动视为无效目标。

网络沿已确认方案B组织。完整生产轨迹开始时复制包含编码、分层融合、预测头及归一化统计的独立预测副本，该轨迹内参数固定，但每次决策仍读取最新状态。在线Actor共享表示接受PPO和实际时间辅助学习，副本提供显式预测数值，PPO重放使用采样时保存的数值。Critic继续估计综合回报。当前周期预测沿既有设计参与输入及势函数，下一周期向量参与上下文，不新增下一周期塑形。

策略对未决任务选择本站执行或合法的相邻后移。后移检查完整前序及已有承诺，首版仅允许不会迫使其他任务新增换站的单工序后移；末站禁止后移。后移改变任务有效归属，不立即转移飞机，不视作完成，也不提前选择未来团队。各组共用统一合法性入口和同一后移范围。

主比较沿现有实验确认稿A／B／C／D组织：

| 组别 | 方法与能力 | 所回答的问题 |
|---|---|---|
| A | 基准计划修复参照：尽量保留站位、团队和顺序，修复可行时间；无后移、无学习预测 | 保持原安排与主动调整有何差异？ |
| B | 固定站位图强化学习：选择站内任务、团队与对齐；启发式时间信息 | 主动站内调整是否有生产收益？ |
| C | 图强化学习加合法单工序相邻后移；启发式时间信息 | 在相同环境中增加有限后移能力有何作用？ |
| D | 完整语义增强方法：分层融合、当前及下一周期机制、当前预测势函数；后移范围同C | 完整语义方案相对于C有何增量？ |

A组必须产生真实可行安排，不能忽略人员冲突而机械平移所有任务。B组若由工作二接入新环境，应标注为适配对照。B、C都可以读取五站状态，因此B到C主要检验后移能力；C到D检验完整语义组合，不能单独归因于某个预测头。

### 3.4 工作三的机制消融

在主比较之后，通过消融回答三个具体问题：时间后果信息是否被策略有效利用，紧邻下一周期是否提供额外信息，分层融合是否有助于联合决策。保留原确认稿的当前周期C／E／F／G／D三通道框架：

| 配置 | 当前周期时间辅助学习 | 当前预测数值进入动作头 | 当前预测用于势函数 |
|---|---|---|---|
| C：启发式参照 | 否 | 否，使用启发式 | 否，使用启发式 |
| E：仅辅助学习 | 是 | 否，使用启发式 | 否，使用启发式 |
| F：辅助学习与预测输入 | 是 | 是 | 否，使用启发式 |
| G：辅助学习与预测塑形 | 是 | 否，使用启发式 | 是 |
| D：完整当前周期通道 | 是 | 是 | 是 |

此表说明既有当前周期通道，不替代完整配置表。只有分层结构、下一周期辅助损失和下一周期数值输入保持一致，相关比较才可解释为当前通道的作用。跨周期及分层对照按原确认稿单独登记开关，正式实施前明确下一周期学习、下一周期输入、分层结构、预测副本、参数规模及动作范围。不将旧编号自动改成一套新的全交叉实验，也不预设模块收益可相加。

分层对照保持可见原始信息和合法动作一致，区分信息组织方式与增加输入字段的影响；下一周期对照区分辅助监督和显式输入的作用。具体对照结构与参数匹配办法在正式协议中说明。若只获得组合差异，结论据此限定，不宣称已经独立隔离每个模块。

## 4. 评价指标与结果解释

### 4.1 与研究问题对应的生产指标

| 研究内容 | 主要生产指标 | 可行性与计算指标 | 机制指标 |
|---|---|---|---|
| 一 | 原静态模型定义的计划完工时间／排程跨度 | 完整可行率、前序与人员约束核查、推理耗时 | 对应联合决策和图表示比较 |
| 二 | 修复计划跨度、参考周期超限、开工／站位／团队偏离及论文综合目标 | 冻结与绑定一致性、修复可行率、修复耗时 | 效率与稳定性分量、结构及基准条件比较 |
| 三 | 整批实际工期、逐周期及累计节拍超期、周期内开工偏差、团队偏离和正式后移 | 合法完成率、失败原因、每步耗时与峰值资源开销 | 当前／下一周期预测误差、分层及跨周期消融 |

工作三整批实际工期以第一架飞机投产至最后一架飞机实际完成的时间范围计算。逐周期分析采用实际脉动间隔，并明确填线、正常生产与排空位置。局部受扰窗口与整批统计范围分别标注，避免将排空后的负荷下降解释为策略恢复能力。

设实际脉动时刻为\(P_q\)，实际周期长度为\(H_q=P_q-P_{q-1}\)，基准节拍为\(H_0\)，累计节拍超期沿确认稿使用：

\[
J_H^{\mathrm{raw}}=\sum_q[H_q-H_0]_+.
\]

每个实际周期结算一次，报告小时量；训练归一化量另行说明。该指标不把同一日历滞后重复累计，也不等同于整批工期。

开工偏差比较工序在各自实际执行周期中的相对开工位置和基准周期内位置，整体周期平移不重复增加该偏差。团队偏离按与基准团队的成员重合比例计算。后移次数、发生后移的工序比例及重复后移情况单列，自然转站和内部候选选择不计为正式后移。

基准偏离、正式后移代价及实际节拍超期依现行规则分别记账。旧稿R_T、R_W过程修订项仍为待核对接口，不能按可反复更改已提交团队的假设继续计费。最终生产评价采用真实日志重算的代价和分项指标，预测势差及训练总回报不代替真实绩效。

### 4.2 语义预测与传播分析

当前周期比较启发式及修正预测相对实际共同脉动的误差，下一周期按有效站位计算就绪偏差预测误差，分别报告MAE及单位或归一化尺度。尚未结算样本不以零标签加入误差；空站和无下一周期目标按有效性掩码排除。在线模型诊断误差与实际决策所用副本误差分别记录。

调度收益与预测误差分开检验。预测更准只说明相应时间信息估计改善，是否带来较短整批工期或较低超期，需要生产指标和消融结果回答。直接受扰飞机与其他飞机的开工、等待、团队及后移变化首先用于描述传播；若估计扰动净影响，则增加同方法、相同初始条件的无扰动配对轨迹，不能将全部变化直接解释为因果损失。

所有质量比较同时报告完成率与失败原因。若排程未完成或违反硬约束，不与完整合法轨迹混为可行结果。质量均值的样本范围、失败实例处理及统计分母在正式协议中固定，避免仅保留成功轨迹而隐去失败比例。

## 5. 训练划分、公平比较与统计安排

训练、验证和测试分别承担学习、模型选择和最终评价。工作三每个学习配置、每个训练种子训练一个覆盖九类场景的策略，五个受扰站位均参与训练；验证与测试采用独立冻结事件集合。按完整事件及生产轨迹划分，不能将同一周期的大量相关状态随机拆分后视为独立验证。

测试期间冻结网络参数及归一化统计量，生产状态和未决任务的决策照常更新。实际结果用于计算标签误差与绩效，不回流测试模型训练。事件生成器可以保存隐藏未来信息，但决策观测、合法性及启发式不得提前读取尚未揭示事件。

各方法共用工艺与人员条件、可见信息边界、测试事件和真实代价。比较时记录动作差异、网络容量、交互预算、训练墙钟时间及测试计算开销。等交互量并不自动意味着等计算成本，完整预测副本的前向及存储开销纳入统计。不同学习方法的调参范围与模型选择原则事先登记。

独立训练种子与同一检查点重复测试场景分别报告。以完整场景或生产轨迹组织配对比较，不将工序或决策步数当作独立训练重复。报告平均表现、波动和配对差异，适当给出置信区间；多方法检验记录校正方式，并区分统计显著、效应大小和实际生产价值。训练种子数、测试数量及最终预算先测成本，再在正式测试前固定。

已有论文的统计结果按原协议使用。工作一原稿的10个独立训练种子，不自动成为新同构版的完成记录；工作二补充随机种子测试，不自动写成相同次数的独立重新训练。两个论文及新增方法之间的比较需根据同一任务和协议建立，不能由不同实验表中的绝对数字推断版本升级收益。

## 6. 分阶段验证与技术难点处理

| 阶段 | 主要工作 | 进入下一阶段的依据 |
|---|---|---|
| 物理过程核查 | 小案例检查完整前序、人员互斥、不可撤回决定、非抢占、同步脉动、合法后移和整批终止 | 形成可人工复核的合法完整轨迹 |
| 计账与标签核查 | 独立日志重算真实费用，检查首次就绪、周期身份、标签回填与有效性掩码 | 费用与事件一一对应，标签不使用错误周期或伪零结果 |
| 信息与预测检查 | 核查隐藏事件不可见；用固定策略轨迹进行时间头小验证 | 明确输入边界及未见轨迹上的误差表现；预测收益仍与策略收益分开 |
| PPO链路与小训练 | 核对历史输入、固定副本及条件掩码重放，跑通C／D等必要链路 | 动作概率可复算，在线辅助更新和副本隔离正确，记录成本 |
| 正式主比较与消融 | 冻结参数、事件清单、预算和指标，完成主比较及必要机制验证 | 获得完整生产结果、分项、统计与计算成本记录 |
| 扩展验证 | 根据主结果考虑更多规模、批量及后续扰动设置 | 扩展目的明确且资源允许，不作为首版全部必做内容 |

技术难点首先在于保证图、状态、动作和实际执行采用一致的工艺依赖与任务身份，尤其避免跨虚拟节点依赖丢失及后移引起隐性连带迁移。其次，时间标签滞后于动作出现，需要跨采样段保留历史记录，区分结果尚未结算与目标无效。再次，预测特征参与PPO时须保持采样和重放输入一致，避免在轨迹中更换副本参数或使用更新后的预测值重算旧动作概率。最后，语义模块可能改善误差而未改善生产结果，因此通过分项指标与消融判断其实际作用，而非以辅助损失下降替代验证。

这些难点已有对应的首版设计与核查顺序，具体实现和效果仍需实验验证。动作条件预测、成组后移、原因解释、其他融合网络及精确神经增量更新继续为后续候选，本稿不增加首版范围。
