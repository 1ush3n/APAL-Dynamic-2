# 开题报告统一术语与当前定义

日期：2026年10月6日；2026年10月10日补充工厂来源、转站耗时、扰动定义及本轮确认的平衡与调度说明。用途：作为背景、综述、研究内容、方法、实验及汇报脚本的共同定义入口。本表依据用户已确认设计、两篇现有论文、数据说明及本轮专业文献核验形成；不新增模型、实验或标题决定。

## 1. 来源与使用原则

标准术语按文献定义使用；本研究自定变量和模块须明确其生产含义。解释性短语可以帮助读者理解，但不将普通掩码、特征拼接或辅助损失包装成新的“范式”“机制体系”。同一个指标不通过更换近义词制造新的概念。

用户最新确认确定研究范围；导师原话提供研究组织要求；原论文确定已有方法和结果的事实归属；README确定数据字段与依赖处理。文献用于支撑概念和比较，不能替代本研究的生产假设或实证。

## 2. 生产、计划与评价术语

| 统一用词 | 本稿中的具体含义 | 应避免的混用 | 依据 |
|---|---|---|---|
| 飞机脉动装配线 | 飞机驻站作业后以脉冲方式向有序站位前移 | 固定式、续动式与脉动式混称；把所有飞机装配都当成本模型 | 方水良等，2021；本研究采用的同步转站规则 |
| 装配线平衡 | 将工序分配到有序站位，在工艺前序等约束下，根据问题设定优化站位数量、周期或相应负荷目标 | 各模型同时优化所有目标；与作业顺序、时间和资源安排绝对分离；把工时总和等同于本站完成时刻 | Boysen等，2007、2022；Becker与Scholl，2006；Bao等，2023 |
| 调度 | 确定工序的执行顺序、起止时刻及资源使用；本课题联合决定工序安排、执行站位与具体人员团队 | 仅指完成工序分站后的站内排序；等同于装配线平衡 | Vieira等，2003；Bao等，2023；Pucel与Roussel，2024 |
| 工序前序约束 | 工艺规定的先后关系，包括经虚拟节点传递的依赖 | 策略选择顺序等同于改变工艺；删除虚拟节点时丢失路径 | 原论文与README；precedence constraints |
| 人员分配／具体团队选择 | 所需人数给定，选择符合资格和占用条件的成员 | 企业用工数量、招聘、任意跨站调人 | 原论文；Zheng等，2025和Fang等，2021用于区分决策范围 |
| 多资源约束 | 总括词，使用时列出本模型实际涉及的人员、站位及既有资源条件 | 引用别人的工具或空间模型后将其写成本研究已建模约束 | 原论文、README与环境配置；不是独立新方法名称 |
| 基准排程 | 无扰动条件下制定、用于生产参照与偏离比较的排程 | 写成只能由工作一提供的算法输入；扰动后随意重置比较基准 | baseline schedule；Vieira等，2003 |
| 重调度 | 响应扰动或其他变化，在模型允许的范围内更新已有排程；工作二具体研究工序延迟开工后的修订 | 所有安排都可改；将工作三提交后的安排重新选队或撤销 | rescheduling；Vieira等，2003；工作二具体规则 |
| 预测—反应式调度 | 预先制定计划，再响应执行中的变化 | “预测”必然表示预测未来扰动、物料到达或故障时刻 | predictive-reactive scheduling；Vieira等，2003 |
| 计划稳定性 | 相对于固定基准排程的改动程度，按各模型的开工、站位和团队指标评价 | 鲁棒性、排程一致性、强化学习训练稳定性互换 | schedule stability／scheduling stability；Vieira等，2003；Herroelen与Leus，2004 |
| 鲁棒性 | 本文提及文献时依其定义，通常关注扰动后的生产性能变化或抗扰表现 | 仅凭计划变化少或少量案例均值好就断言鲁棒 | Vieira等，2003；鲁棒调度文献具体定义 |
| 工序延迟开工 | 扰动使尚未实际开工工序的最早可开工时刻推迟 | 已开工作业暂停、抢占、加工时长随机延长混用 | 本研究扰动抽象；工作二现有实证为物料就绪延迟 |
| 非抢占执行 | 工序实际开始后连续执行至完成 | 已开始任务可以撤回、暂停后换站或换队 | non-preemptive；原论文及工作三确认规则 |
| 基准节拍 \(H_0\) | 固定的计划周期长度／比较参照，按现有基准定义取得 | 与实际周期 \(H_q\) 混称；强制按名义时刻放行 | 当前模型定义；不对文献中的takt time、cycle time作无条件一一对应 |
| 实际周期 \(H_q\) | 相邻两次实际脉动之间的间隔：\(P_q-P_{q-1}\) | 同一日历滞后在多个周期重复当作超期 | 工作三实际日志与确认稿 |
| 工序前序就绪 | 前序条件已满足；实际开工还受位置、人员和开工下界限制 | 与本站全部任务完成后的站位就绪混用 | README及执行规则 |
| 站位就绪 \(F_{k,q}\) | 本站首次实际完成当前有效物理任务并满足既有转站条件的时刻 | 预约、派工或基准计划结束即视作就绪 | 工作三实际事件定义 |
| 实际同步脉动 \(P_q\) | 有效占用站位最晚就绪时刻；转站等耗时已分摊计入工序标准工时，不重复增加 | 某站完成即可单独转站，或名义周期到点自动放行 | 工作三：\(P_q=\max_{k\in K_q}F_{k,q}\) |
| 计划完工时间／排程跨度 | 按工作一、二原模型定义的计划时间指标 | 等同于多架次整批实际工期 | 两篇原论文；引用时保留原时间起点与统计范围 |
| 整批实际工期 | 第一架飞机投产至最后一架飞机实际完成的时间范围 | 用修复模板跨度代替真实批次完成时间 | 工作三验证详细稿 |
| 多架次协同 | 不同飞机和站位的安排服从同步脉动及连续生产目标 | 必然等同于多智能体通信或多型号混流 | 本研究问题定义，不宣称独创该通用概念 |

## 3. 图网络、语义与更新术语

| 统一用词 | 明确定义及使用方式 | 证据／状态 |
|---|---|---|
| 同构图 | 工作一把原实体和连接组织为单一图，在图传播中共享规则与参数，不按实体／关系类型设置独立传播通道；实体差异可作为属性保留 | 图类型的标准区别见Hu等，2020；本研究最小替换的具体算子待实施核对 |
| 异构图 | 显式区分工序、站位、人员和技能及其关系类型，在信息传播中利用这些区别 | 标准概念见Hu等，2020；工作二的图结构按当前论文 |
| 按关系类型组织信息 | 前序、技能、资格、归属等分别参与编码 | 用于解释“类型化关系”；不是额外技术名称 |
| 自回归联合决策 | 后一个条件选择读取前面选择结果，工序、站位和团队成员选择共同形成一个完整动作 | 原论文的方法；多步条件选择不自动成为分层强化学习 |
| 动作掩码 | 根据实际状态与硬约束屏蔽非法候选；留站／后移检查进入统一入口 | invalid action masking；Huang与Ontañón，2022；掩码不是新增智能优化范式 |
| 图编码范围 | 使用环境可见的完整工序图及资源关系，已完成节点可保留上下文 | 用户已确认；虚拟依赖显式保留或等价投影 |
| 分层读出／汇总 | 从图表示中按飞机身份、站位及周期角色汇总未完成物理任务，再形成整线信息 | 工作三首版设计；不把未完成任务集误作唯一图编码范围 |
| 站位任务集 | 由基准分配、当前有效安排和实际记录派生的任务集合 | 统一替代责任池、任务池；不是额外初始排程求解模块 |
| 事件与后果语义 | 本研究定义：当前状态及最近变化对应的生产时间后果，包括本次脉动修正和紧邻下一周期站位就绪偏差 | 自定研究内容，须以明确输入、时间量和监督来源说明；不捏造对应英语固定术语 |
| 状态后果预测 | 根据当前可见状态，在当前后续策略下预测实际执行产生的时间结果 | 首版已确认；不是每个候选动作的因果收益或最优工期 |
| 有符号就绪偏差 | 下一周期本站就绪相对 \(P_q+H_0\) 的早晚；正值晚，负值早 | 负值不保证可插入等长新任务；本站偏差不等于整线超期 |
| 标签有效性掩码 | 排除无飞机或不存在下一周期的监督目标 | 有飞机但无任务仍可有效；待结算结果不能填成零标签 |
| 生产事实刷新 | 开工、完成、正式后移、脉动或时间推进改变对应实际状态 | 各层受影响范围和频率可以不同 |
| 神经表示重算 | 首版每次完整决策前由最新一致状态重算动态图表示及预测 | 内部条件选择共用事实快照；静态拓扑缓存不等于嵌入永久不变 |
| 训练参数更新 | PPO与辅助监督按采样和训练组织更新在线模型参数 | 与生产事件发生频率不同；测试参数和统计冻结 |
| 固定预测副本 | 一条完整生产轨迹开始时复制编码、融合、预测头及归一化统计，轨迹内参数固定，仍读取每次最新状态 | 网络方案B；与实验B组不是同一个编号体系 |
| 时间辅助监督 | 用实际执行结果训练在线共享Actor表示及时间预测头 | auxiliary tasks的一般依据见Jaderberg等，2017；具体生产收益待验证 |
| Critic | 估计训练奖励对应的累计回报 | 与明确时间标签预测职责不同；不声称Critic没有未来评价能力 |

## 4. 具有否决效力的当前规则

1. 工艺与虚拟依赖以唯一数据集和README为准。虚拟节点不计物理工作量、需求人数或物理任务数；零工时物理任务不能被误删。无显式或传递前序的任务可以初始前序就绪，仍需满足其他开工条件。
2. 工作二冻结范围按原论文的基准开工时刻与重调度边界确定，继承原条目及已使用人员的站位绑定。不能用工作三的实际提交规则反向替换工作二模型。
3. 工作三只有一个实际事件驱动仿真环境。完整执行决定形成后不可主动撤回或更改，包括未开工预约；新扰动只可依据开工条件使既定安排被动顺延。已开始工序非抢占。
4. 同刻开工与扰动按已确认顺序先处理开工。这适用于真实安排已满足开工条件的任务，不为扰动揭示后新作出的选择创造先开工权利。
5. 首次本站就绪后等待，不设计就绪撤销处理。空站不参与整线最大值；存在待投产飞机时，在实际脉动进入一号站位。五站位及其组织方式来自调研工厂，不将其概括为全部飞机脉动装配线的通用结构。
6. 后移每次只到紧邻下一站，且不会迫使其他任务新增换站；已提交和运行中的任务不能后移。后移改变有效归属，不提前移动飞机、预约未来团队或将任务计为完成。到站后新阶段可再次作合法后移决定，按增量代价计账。
7. 原始参考排程、当前有效安排、实际执行记录分别保留。它们是三类信息记录，不是可反复修改的三个计划层。
8. 首版显式预测只覆盖当前与紧邻下一周期，输入只含当前已知信息。五站信息不等于五个未来周期的详细预测。
9. 当前预测用于动作输入及已有势函数；下一周期向量用于动作上下文，首版不新增下一周期势函数或预测风险罚项。真实生产代价、训练塑形和辅助损失分别记述。
10. MLP为首版融合方式。动作条件预测、成组后移、其他融合网络、原因解释及精确神经增量更新仅为后续候选，不混入首版实验承诺。
