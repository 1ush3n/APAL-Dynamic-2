## 四、研究内容三能否称为语义增强

判断：可以保留，但必须明确指生产时间结果的含义，并以具体预测任务和信息使用方式说明，不能仅凭新增MLP或分层汇总就称为语义增强。这里是本课题对方法作用的定义，并非宣称采用了一个已有固定名称的标准网络。

| 已确认设计 | 具有明确生产含义的信息 |
|---|---|
| 工序／飞机摘要 | 当前完成、执行及剩余作业状态，解释为各架飞机的实际进度 |
| 站位摘要 | 本站任务和人员条件，关联本站何时具备转站条件 |
| 整线信息 | 各站共同决定的实际脉动时刻 |
| 当前周期预测 | 本次共同脉动时刻相对现有估计的有符号修正 |
| 紧邻下一周期预测 | 下一周期各站就绪时间相对参照时间的有符号偏差 |
| 实际轨迹监督及策略输入 | 用实际执行结果训练预测，预测信息再供联合调度策略使用 |

其中，区分实体和关系已属于研究内容二，事件更新也不能单独证明语义增强。研究内容三更明确的增加，是将分层生产状态与具有时间单位、可解释的实际生产结果联系起来。预测依据当前状态和当前策略下的执行结果，不声称提前知道未发生的扰动，也不将状态后果预测解释为动作的因果效应。

候选正文解释：本研究中的语义增强，是在工艺与人员关系编码的基础上，将各架飞机和站位的当前进度与同步脉动、下一周期站位就绪等生产时间结果联系起来，并利用这些信息支持多架次作业安排。

上述解释暂未追加正文，待用户确认，以免重复已有3.2.3和4.4的时间预测说明。

可选名称：

1. 保留当前“基于语义增强图网络的多架次飞机装配协同动态调度方法”：承接导师原有递进，需要紧接题名解释语义所指。
2. “基于图神经网络与时间预测的多架次飞机装配协同动态调度方法”：更直接说明图编码与预测两个组成，评审容易理解。
3. “基于分层图表示的多架次飞机装配协同动态调度方法”：突出飞机—站位—整线信息组织，但题名不直接体现时间预测。

相关证据及边界：Wang等的Heterogeneous Graph Attention Network将不同元路径的重要性称为semantic-level attention，其“语义”具体指元路径所表达的关系含义，与本课题的生产时间结果不同，不能直接作为两者完全相同的依据。Jaderberg等的Reinforcement Learning with Unsupervised Auxiliary Tasks说明可通过共享表示结合辅助学习任务，为时间预测辅助状态学习提供方法参考，但不能据此证明本课题已取得性能提升或“语义增强”是该预测模块的标准名称。
