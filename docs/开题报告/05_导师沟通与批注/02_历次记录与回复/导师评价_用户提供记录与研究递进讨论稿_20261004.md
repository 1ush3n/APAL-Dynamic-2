## 二、后续必须遵循的论证要求

1. **生产问题逐步扩展：**无扰动静态调度 → 工序延迟开工扰动下的动态调度 → 多架次连续执行中的协同动态调度。工作一、二均含人员决策，不删除工作一人员因素以制造递进。
2. **图表示逐步深化：**同构图 → 异构图 → 语义增强图网络。每次深化都应对应具体问题，不仅更换网络名称。
3. **一到二的理由：**统一同构表示对不同关系的针对性处理仍需加强，且无扰动研究未覆盖扰动后的调整。“工作一提供基准排程”不作为研究衔接依据。
4. **二到三的理由：**受扰周期计划修复尚需扩展到在制多架次实际执行与跨周期影响；同步脉动使局部延迟影响其他飞机的转站及后续任务。需要在工序／飞机、站位和整线层面理解事件的时间后果，用于统筹当前与紧邻下一周期的安排。

## 三、三项工作衔接段（2026年10月4日20:40用户确认）

本课题围绕飞机脉动装配线的工序排序、站位分配与人员分配，按照“无扰动静态调度—扰动下动态调度—多架次协同动态调度”逐步展开，并相应研究同构图、异构图及语义增强图网络的状态表示方法。

工作一首先面向无扰动条件下的静态调度问题，采用同构图统一组织工艺与资源信息，通过自回归策略联合进行工序排序、站位分配和人员分配，构造可行排程。在此基础上，对工艺前序、技能匹配和资源安排等不同关系的针对性处理仍需加强，且无扰动条件下的研究尚未覆盖工序延迟开工后的计划调整。因此，工作二引入异构图，分别组织不同实体及关系的信息，并研究工序延迟开工扰动下兼顾完工时间与计划稳定性的动态调度。

工作二重点研究受扰周期计划的修复，尚需进一步考虑不同在制飞机在实际执行中的相互影响。在多架次连续生产中，各站位承载不同飞机，其任务进度共同决定全线同步脉动的时刻；局部延迟还可能影响其他飞机的转站与后续周期安排。因此，工作三在异构图表示基础上引入事件与后果语义，在工序／飞机、站位和整线层面预测当前及紧邻下一周期的时间后果，将现场状态进一步转化为对全线运行影响的理解，为多架次协同动态调度提供依据。

## 六、写作与实施边界

- 不把同构图写成完全无法表达约束或耦合；异构表示的独立优势仍需对应证据，合法性仍由已有约束机制保证。
- 工序延迟开工是扰动形式；不在此段限定尚未最终确定的具体原因，也不增加对未来扰动发生时间或程度的提前预知。
- 不把工作二简化为只能处理一架飞机；其固定模板稳态展开与工作三的在制多架次实际执行、受扰切换问题应区分。
- 事件与后果语义沿用已确认的实际执行结果监督；“情景理解”不等于新增人工情景分类，也不等于预测尚未发生的扰动。
- 多架次“协同”落到共同脉动约束及当前／下一周期影响下的任务统筹，不增加独立智能体通信机制。
- 本段中的“研究”“预测”描述研究方案；设计确认、代码实现与性能验证分开，不将新段落当作全部机制已实现或实验已证明有效。
