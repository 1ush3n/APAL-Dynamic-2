# 工作一重点问题：文献核对与开题表述校准

日期：2026年10月4日。目的：回应用户对“人员占用与站位绑定最值得突出”的质疑，为开题确定有证据的研究问题范围。此次核对不修改已定标题、原论文或代码；不要求开题前立即补做实验。前轮其余机制解释获用户同意，因素主次不作为已确认结论。

## 1. 核对结论

现有证据支持围绕**工艺前序与资源约束下，工序排序、站位分配和人员团队选择的耦合优化**组织工作一。人员占用和站位绑定有研究依据，也能解释后续选择空间，但尚无证据证明它们是用户数据中最主要的瓶颈，或比工序排序贡献更大。

本轮采用“先用文献说明问题值得研究，后用对应实验判断机制作用”的安排。开题允许明确研究问题、方法及验证路径，而不预先给每种因素排重要性顺序。这是本次有限文献核对的判断，不代表完成了全领域系统综述或新颖性查全。

## 3. “工序排序”的准确含义

需区分三个层次：

1. **给定工艺前序。** 数据中的依赖关系是硬约束，不是本算法可以重新设计的工艺流程。
2. **排程构造优先次序。** 每一步在合法候选中选择下一道要安排的工序，是策略可优化的决定。
3. **最终加工时序。** 由构造次序、站位与团队、前驱完成、人员日历和释放约束共同形成；构造次序不应未经核对直接视为真实开工次序。

当前同模板飞机的模型也不等同于混合机型投产排序。没有新增换型准备时间或产品顺序决策。

| 决策／规则 | 影响路径 | 当前可以说的结论 |
|---|---|---|
| 下一道安排哪道工序 | 改变资源被谁优先占用、后继何时可被安排 | 影响后续排程；强弱待验证 |
| 工序安排到哪个站位 | 改变各站任务负荷、单向流动可行域和可用人员组合 | 需要与排序、人员共同考虑 |
| 选择哪些具体成员 | 改变工时及特定人员的占用与释放 | 人数相同也未必有相同排程效果 |
| 未绑定人员首次使用 | 按模型规定形成站位归属，限制未来选择 | 是既有约束及耦合机制，不自动成为最主要创新 |

## 4. 开题中的建议表述

**工作一问题定位建议：**面向飞机脉动装配线的工艺前序与多资源约束，研究工序排序、站位分配和具体人员团队选择的联合优化，采用同构图组织调度状态，通过条件化决策与可行分配构造基准排程。

这是一句可压缩的定位草案，未替换此前已确定的工作标题，也不是完整正式开题正文。正文可解释一种耦合例子，不必证明哪种因素“最突出”。

保留：联合动作、规定团队人数、具体成员选择、首用绑定、合法性掩码及前向时间分配。修正：不把人员绑定列为已证明的首要瓶颈，不把整体模型结果拆成各模块已经独立验证的贡献。

## 5. 后续如何判断主次

先核对已有变体到底改变了哪些条件；不根据不同干预的百分比大小直接排列机制贡献。后续若需要判断，可分别固定其他决策规则，对工序优先策略、人员团队选择、预绑定／内生绑定作公平对照。报告可行率、模板跨度、耗时及场景差异，保留机制相互作用的可能性。

这些对照回答特定配置下的作用，不保证得到唯一、与场景无关的因素排名。不能通过删除工艺前序等硬约束制造比较，也不把首用绑定带来的决策空间变化误称为只换一个网络层。
