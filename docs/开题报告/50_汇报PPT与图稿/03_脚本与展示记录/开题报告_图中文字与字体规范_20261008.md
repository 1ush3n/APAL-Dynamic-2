# 开题报告图中文字与字体规范

确认日期：2026年10月8日。适用图稿：总体技术路线图、分层信息融合与更新图、283道工序数据的工艺前序结构图。本文件规范图内文字，不替代学校对报告正文的排版要求。

## 字体与用途

| 文字类别 | 本次实际使用的字体 | 样式与用途 |
|---|---|---|
| 中文与中文标点 | Droid Sans Fallback | 中文黑体风格，用于标题、模块名称、说明和图内注释 |
| 英文、数字与ASCII标点 | Nimbus Roman | Times风格衬线字体，用于MLP、PPO、工序编号和数量等 |
| 加重的英文与数字 | Nimbus Roman Bold | 对应模块强调，与常规英文字体同一家族 |

以上列的是导出图实际采用的字体名称。Droid Sans Fallback不是SimHei，Nimbus Roman不是Times New Roman；不能将风格相近写成字体文件完全相同。三张图采用同一套字体文件，中文字体子集与英文、数字字体子集分别嵌入SVG，并据此渲染PNG。

## 字号与文字处理

- 图标题使用25—27个绘图单位；模块名称主要使用20—21个单位；说明及注释使用15—19个单位。三张图保持相同的标题、模块、说明层次；字号单位是SVG坐标单位，不冒称Word磅值。
- 中英文在同一行内按字符使用上述字体，不把MLP、PPO、283或工序编号全部交给中文字体。
- 保留标准英文缩写，不为不同字体另改算法名称。工序标识保持原始数据拼写，分组编号不改成物理站位。
- 中文标点、图注和正文按报告统一规范处理；图内文字保持简短，具体执行约束放在正文解释。

## 图形与导出

- 白底，黑色文字、边框和箭头；不用彩色填充、阴影或装饰性图标。
- 两张技术图沿用已确认的布局、模块分工、动作规则和更新频率，仅更新字体。
- 数据图采用单张整体图，在A-3所属框内节选3道真实工序，不另设左右子图。
- 保留可编辑SVG及PNG。当前PNG按SVG尺寸的2倍导出；插入Word时维持纵横比，检查最终排版尺寸下的说明文字是否清晰。
- SVG嵌入字体有助于保持显示一致，但不同编辑软件可能不支持相同的字体加载方式；PNG已经固定本次字体外观。继续编辑SVG时需保留字体定义，或使用配套复核包中的字体文件。

本次已核对图中的中英文、数字和标点均有对应字形，三张PNG完成视觉检查。正式报告的工作一、二标题未因字体统一而改变。
