# 开题PPT：生产问题与图表示表述对照

> 2026年10月9日。本轮已按用户确认修改主PPT：背景先讲生产问题，研究内容和技术路线再解释图表示。下列“加入图表示”文字是候选，未替换当前关键研究问题。背景两页保持分开，原研究内容第9、10页合为一页。

## 1. 当前关键研究问题与另一种写法

| 对应研究 | 当前PPT采用的生产问题 | 加入图表示后的候选文字 |
|---|---|---|
| 研究一 | 工序、站位与人员选择相互制约，如何生成满足约束的高效联合排程？ | 如何以同构图统一表示工艺与人员信息，支持满足约束的工序、站位和人员联合安排？ |
| 研究二 | 工序延迟开工后，如何调整受影响的安排，兼顾完工时间与计划稳定性？ | 如何用异构图区分工艺与资源关系，在工序延迟开工后调整计划，兼顾完工时间与计划稳定性？ |
| 研究三 | 局部安排与扰动可能影响其他站位，如何协调多架次飞机的共同转站及下一周期任务？ | 如何利用语义增强图网络表示多架次进度及其跨站位影响，协调共同转站与下一周期任务？ |

两种写法回答不同层次的问题。当前文字先说明生产中需要解决什么；候选文字进一步指出拟用什么表示和方法。背景页沿用当前文字，候选适合放在方法介绍前的过渡中。

“跨站位影响”包括局部安排或延迟沿工艺前序与人员占用产生的影响，以及某站完成较晚通过共同转站影响其他站位和下一周期。局部延迟不必等量传递到整线。已有飞机装配研究已考虑多站协调，不能概括为传统方法均无法处理跨站位问题；本课题重点在于结合具体人员联合决策、多架次实际进度和当前／下一周期执行。

## 2. 研究内容页采用的三项介绍

**研究内容一：**面向无扰动生产，采用同构图表示工艺与人员状态，联合安排工序、站位和具体人员，构造可行排程。

**研究内容二：**通过异构图区分工艺与资源关系，开展联合调度；延迟开工后保留不可修改安排，调整后续计划，兼顾完工时间与计划稳定性。

**研究内容三：**面向多架次飞机连续装配，结合语义增强与分层信息融合，协调各站任务；语义指当前进度对共同转站及下一周期的影响。

第三项用上述短句解释“语义”。技术路线中仍保留完整图编码、飞机／站位／整线汇总、当前与紧邻下一周期的时间预测以及联合决策等已确认内容。这里的“连续装配”指多架次先后进入装配线，不指飞机连续移动；驻站作业后共同转站的生产规则不变。

研究内容页的两次递进分别写为“进一步区分关系，并响应工序延迟开工”“进一步跟踪多架次进度，理解跨站位影响”。基准排程仍属于模型信息，不作为工作一到工作二的研究衔接。
