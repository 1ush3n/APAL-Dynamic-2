# seed42 历史结果判读勘误

本文件只补充解释，不改写 seed42 原始日志、权重或轨迹。

1. R1 是保持性正结果。降低学习率后参数位移减小是预期机制；“不能靠减速”不是预设验收条件。结果不证明长期保持或恢复学习效率。
2. R2 的三个点均低于 REF。相对改善由原始费用动态计算：
   - 128 步：REF=0.65078746180350677，R2=0.63607370225573823，改善=0.014713759547768546，相对改善=2.26092%。
   - 256 步：REF=0.32059127841385598，R2=0.028353581126294707，改善=0.29223769728756127，相对改善=91.1558%。
   - 512 步：REF=0.70725716373484449，R2=0.68509268600385798，改善=0.022164477730986509，相对改善=3.13386%。
3. R0 直接冻结随机动作产生的费用，与随机样本影响 PPO 梯度方向是不同问题；其随机轨迹也不能与 greedy 评估构成同口径优势证明。
4. R0 实际采样 210 步；旧批总实际交互=2258（R1–R4 各 512），计划 2560 不等于实际；不补跑缺少步数。
5. R3 只说明该改动在该配置下恶化；优势尺度还会改变 policy 相对 value/entropy 尺度及裁剪、优化器作用，不能据此证明方向已被噪声主导。
6. 相近参数 L2 不等于相近策略变化；如果包含 critic，更不代表动作分布变化。R4 是候选，不因单个终点改善而成为唯一根因。
7. 校准 MC target 均值/标准差=0.49898746609687805/0.0006183760706335306；常数预测器训练/留出 MSE=3.805278488977178e-07/3.808545912427269e-07，校准后误差不可据此宣称 critic 准确；本轮不再校准。
8. 完工轨迹满足 G_shaped=G_raw−βΦ(s0)，前轮 +0.5 是固定平移，不能因回报正负不同称目标冲突；截断保留端点势函数项。
