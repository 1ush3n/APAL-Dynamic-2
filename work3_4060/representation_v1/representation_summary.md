## 1. 核心结论与判定

本轮完成了 Section 11.4 规定的 **Method C ($\beta=0.1$, seed 42, 4096步)** 匹配对照训练，与已有 **Method F ($\beta=0.1$, seed 42, 4096步)** 及 **Method D ($\beta=0.1$, seed 42, 4096步)** 构成了在完全相同种子、相同初始权重指纹、相同预算、相同 $\beta=0.1$ 下的**纯表征机制消融组**。

### 1.1 表征净贡献 $\Delta_{\text{repr}}$
表征净贡献定义为：
$$\Delta_{\text{repr}} = \frac{1}{4} \sum_{s \in \text{Val}} \left(J_{C, \beta=0.1, s} - J_{F, \beta=0.1, s}\right)$$
（正值表示引入时间辅助头及修正时间输入的 Method F 费用更优，负值表示无辅助表征的 Method C 更优）。

- **4个 Validation 场景主口径平均**：
  $$\Delta_{\text{repr}} = +8.29073202 \times 10^{-3} \quad (+0.00829)$$
  - **F 胜 4 / 4 场景 (100% 胜率)**，无平局，无翻转。
  - **平均综合费用 $J_{\text{total}}$**：$F(\beta=0.1) = 0.04491$ vs $C(\beta=0.1) = 0.05320$（$F$ 比 $C$ 费用降低 **15.58%**）。
- **Nominal 场景单列**：
  $$\Delta_{\text{repr, NOMINAL}} = J_{C, \beta=0.1} - J_{F, \beta=0.1} = +8.25801020 \times 10^{-3}$$
  - $F(\beta=0.1) = 0.04491$ vs $C(\beta=0.1) = 0.05316$。

### 1.3 机制分解与准确费用术语
1. **费用分项权衡（术语严格对齐）**：
   - 观察费用分项，$F(\beta=0.1)$ 相比 $C(\beta=0.1)$：
     - **团队替换偏差费用 $D_{\text{team}}$**（非班组冲突）：从 $0.02167$ 降至 $0.00917$（减少 $0.01250$）；
     - **计划修订费用 $J_{\text{revision}}$**（非返工费用）：从 $0.02658$ 降至 $0.02245$（减少 $0.00413$）；
     - **周期内开工时间偏差费用 $D_{\text{time}}$**（非最终工期延期罚款）：因工期拉长（690.35h $\to$ 824.08h）从 $0.00495$ 上升至 $0.01329$（增加 $0.00834$）；节拍与后移费用 $J_{\text{takt}} = 0, J_{\text{postpone}} = 0$；
     - **净收益**：团队替换偏差与计划修订费用的减少（$0.01663$）大于周期内开工偏差费用的增加（$0.00834$），使净综合费用降低 $0.00829$。
2. **显式推进行为观察**：
   - $C(\beta=0.1)$ 与 $D(\beta=0.1)$ 均表现为 0% 显式推进（0/210，工期分别为 690.35h 与 692.88h）。
   - $F(\beta=0.1)$ 呈现约 47.10%（187/397，Nominal 为 186/396）的显式推进，通过工期让渡获得了更优的团队替换和修订协调，但该等待策略是否在所有现场普遍最优仍属假说。
3. **与标准基准 $C(\beta=1.0)$ 的关系**：
   - 标准基准 $C(\beta=1.0)$ 平均费用为 $0.02657$。
   - 当将 Method C 的 $\beta$ 从 $1.0$ 降至 $0.1$ 时，其费用大幅退化至 $0.05320$（+100.2%），表明在弱势函数引导（$\beta=0.1$）环境下，辅助表征（Method F）能有效弥补弱势函数引导的损失，将费用显著降至 $0.04491$。
